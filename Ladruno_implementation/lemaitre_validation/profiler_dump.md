## Caveats

- **µs/elem** (per-element tangent) is the clean comparator — same op, same instrumentation. eas (1 GP + Kstab) < bbar (8 GP).
- Totals (`cpu_ms_total`, `*/step` wall) are unreliable on Windows (the profiler CPU clock is a Win32 stub); trust the python wall-clock and µs/elem.
- `nElem`/`nNode` populate only with the `OpenSeesCommands.cpp` patch that sets them from the live `Domain` (additive `// Ladruno` hook) — **requires a rebuild**; they read 0 on pre-patch binaries.
