| **WP-192 — threaded element loops for the Paper 1 element set** ([[192_ladruno_threaded_element_loops_adr]]; extends WP-107 / ADR-75b). Measured first: on the rev3 1D deck at 2 ranks the element loops are ~85 % of a step on the critical rank and ASDShellQ4 is > 99 % of them, so with METIS / fewer ranks / WP-188 reuse they become the floor. **What ships:** (1) a PER-TYPE opt-in replacing WP-107's all-or-nothing allowlist: maximal runs of audited elements are threaded, every other element runs alone in its serial place (`Element::ladrunoThreadSafeUpdate`, new `::ladrunoThreadSafeForm`, `::ladrunoThreadSafeCommit`, `Material::ladrunoThreadSafeForm`, all default false); (2) the integrators' element TANGENT and RESIDUAL loops (ADR-75b loops B/C) as a **chunked compute + ordered serial scatter** (`SRC/analysis/integrator/LadrunoThreadedAssembly.{h,cpp}`): element matrices formed in parallel into per-chunk slots, scattered by one thread in the serial order with the same `addA/addB` calls, so A and b are BIT-IDENTICAL to serial at any thread count; bounded buffer (chunk x idSize^2), no colouring, no atomics, no per-thread SOE copies; (3) the element COMMIT loop of `Domain::commit`; (4) per-thread twins of the class-wide pools on those paths (FE_Element tangent/residual, TransformationFE scratch, Element Rayleigh pool, Matrix solve/invert/triple-product work area); (5) hybrid MPI + threads on explicit acknowledgement (`ladrunoThreads <n> -hybrid`, `LADRUNO_THREADS_HYBRID=1`; WP-107's MPI refusal stays the default); (6) `ladruno_parallelFor` + region flag + `LadrunoOutputGuard` + the `LADRUNO_THREADS_LOOPS` bisection mask in `SRC/utility/LadrunoThreads.{h,cpp}`. **Thread-safe (statics -> thread_local, accumulators serialised):** ASDShellQ4 (+ both transformations, ASDEICR), LayeredShellFiberSection, ElasticMembranePlateSection, PlateFromPlaneStress, PlateFiber, PlaneStress, PlateRebar, ASDConcrete3D / ASDConcrete1D (IMPL-EX error diagnostics as per-thread partials folded before any read), Hysteretic, Elastic, ElasticIsotropic 3D, stdBrick (+ shp3d), ForceBeamColumn3d (+ FiberSection3d, LinearCrdTransf3d, Lobatto/Legendre), ASDEmbeddedNodeElement, ASDAbsorbingBoundary3D (update/forms; commit serial: ABSORB_LEAK). **Verified:** default 1 thread byte-identical to the base binary and 2/4/8 threads byte/dataset-identical to serial on the rev3 1D serial window (Pardiso, MKL 1 thread); `tests/test_wp192_threaded_element_loops.py` (full-field md5 per step at 1/2/4 threads, mixed domain, repeated-run race probe) with three mutations killed; WP-107 suite 18/18. **Measured** (1D rev3 window, 2 ranks, hybrid, local): element loops 1.71x / 2.73x / 3.38x and step 1.37x / 1.70x / 1.80x at 2 / 4 / 8 threads per rank; the remaining floor is commit's non-element part (recorders + EnergyBalance, ~850 ms of 3 753).
