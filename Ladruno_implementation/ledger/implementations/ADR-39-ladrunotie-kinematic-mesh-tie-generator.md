| **LadrunoTie — kinematic mesh-tie generator** ([[62_ladruno_kinematic_mesh_tie_adr]]) — setup-time generator (NO enforcement code) for a non-conforming explicit mesh-tie. Pairs each slave node to its nearest master facet (reusing the ADR-39 bucket-sort broad phase + `LadrunoContactProjection` closest-point projection + shape weights), then emits one ordinary `EQ_Constraint` per slave node per translational DOF (`u_s = Σ N_i u_{m,i}`); the user runs `constraints LadrunoProjection` (or any EQ-aware handler) to enforce it — exact, dt_cr-neutral, momentum-clean, no fictitious mass. The constructive successor to the shelved penalty route ([[61_ladruno_contact_bipenalty_adr]]). Named refusals: BLOCKER-1 (slave/master not node-disjoint, or a slave listed twice ⇒ MP-chain/double-constraint), BLOCKER-2 (a tied slave DOF carries no lumped mass), OQ-3 (slave off the master manifold ⇒ require conforming-at-interface geometry, no IC snapping). **P1** = solid–solid, node-to-segment collocation (nps 3/4): `LadrunoTie -slaveNodes ns s.. -masterFacets nps nf m.. [-dof nd d..] [-tol frac]`. **P2 (integral mortar, `-mortar`)** = tie the slave SURFACE to the master surface in the weak sense: assemble global mortar `D_IJ=∫N_I^s N_J^s dΓ`, `M_IK=∫N_I^s φ_K^m dΓ` over the clipped overlap (reusing `LadrunoMortarKernel::integratePair` verbatim), condense once at setup `u_s = P u_m`, `P = D⁻¹M`, emit per-slave rows. **KEY: pre-inverting D globally makes every P row tie to MASTER nodes only ⇒ no MP-chains ⇒ NO handler change + NO kernel change** (the ADR's "needs chain support" premise was avoidable). Variationally consistent / optimal for genuinely non-matching interfaces (no coincident nodes). `LadrunoTie -mortar -slaveFacets npsS nf s.. -masterFacets npsM nf m.. [-dof..] [-tol..] [-outward ox oy oz]`. Mortar guards: coverage-ratio (cover/fullCov via self-clip — refuse a slave protruding past the master), conforming-gap (g̃/area), post-solve partition-of-unity (catch ill-conditioned D). **P2.1 (`-mortar -dual`)** = DUAL/biorthogonal (Wohlmuth) slave basis ψ=Aᵉ·N per slave facet (`Aᵉ=diag(∫N)·(Dᵉ)⁻¹`) ⇒ `D_dual` DIAGONAL ⇒ `P=D_dual⁻¹M` is LOCAL/sparse (each slave ties only to masters under its own facet support) ⇒ small local handler groups at large interfaces. Built from the SAME `integratePair` Dᵉ/Mᵉ (a per-facet npsS×npsS solve) ⇒ NO kernel change, NO handler change; default OFF = the standard dense P (byte-identical). Preserves linear completeness (row-sum LUMPING D would break the patch — dual is the CORRECT sparsifier). Composes with P3 (verified: `-mortar -dual` on an ndf-6 shell tie crosses a rigid rotation exactly on all 6 DOFs — `test_mortar_dual_rigid_rotation_crosses_tie`). **P3 (shell / rotational, ndf 6)** = tie the ROTATIONAL DOFs of an ndf-6 shell node with the SAME per-slave transfer P (`θ_s = Σ P_sk θ_{m,k}`); the default `-dof` becomes 1..6 for a 3D ndf-6 node (`-dof`-selectable, e.g. drop the drilling DOF or `-dof 3 1 2 3` for translations only). Reuses BOTH modes (collocation weights + mortar D⁻¹M row) verbatim — no new P math. The projection handler accepts the extra rotational EQ rows unchanged (every (node,dof) is an independent union-find vertex ⇒ master-only rotational rows). Gated by a PER-DOF BLOCKER-2 mass scan: `ShellMITC4`/`ASDShellQ4` `getMass()` NEGLECT rotational inertia, so a default shell tie is refused (named) unless the user adds nodal rotary mass (`mass $n 0 0 0 mrx mry mrz`) — escape hatch `-dof 3 1 2 3`. Scope = shell-to-shell (same P on rotations); shell-to-solid (`θ=½∇×u`) deferred. **P3.1 (`-hermite`, collocation only)** = rotation-consistent CUBIC HERMITE w–θ transfer for ndf-6 shell EDGE (butt-joint) ties: the linear-complete P leaves an O(h²) residual on the transverse displacement w when the bending curvature varies ALONG the interface — `-hermite` reconstructs the shell-normal translation and the interface-tangent slope from the master edge nodes' (w, θ_t) pairs (`u_s = (I−n⊗n)ΣN_k u_k + n·[ΣHw_k(n·u_k)+Hp_k(e·θ_k)]`, `θ_s = (I−e⊗e)ΣN_k θ_k + e·[ΣdHw_k(n·u_k)+dHp_k(e·θ_k)]`, slope = θ·e with e = t×n from u=θ×r ⇒ ∇w=n×θ; n-sign-invariant). Exact through cubic w (O(h⁴) beyond), exact on every P3 case; Kirchhoff assumption ⇒ bounded O(γ·h) on shear-deformable data. **Emission-level only (the OQ, answered in source): `EQ_Constraint` stores per-retained (node,dof,coef) triples and the handler's buildGroups has no retained-dof==constrained-dof assumption ⇒ mixed w←(w,θ) rows need NO kernel/handler change. Mortar-Hermite would (integratePair has no per-GP hook) ⇒ collocation-only, refused with `-mortar`.** Named refusals: full 6-DOF tie required, ndf-6 both sides, edge/corner projections only (interior refused). Default OFF = byte-identical. **P4 (`-shellSolid`, [[64_ladruno_shell_to_solid_tie_adr]])** = shell-EDGE↔solid-FACE plane-section tie, the one genuinely NEW operator of the family and its LAST rung: the SOLID face nodes are the SLAVES, the ndf-6 shell edge polyline (`-masterEdge nseg a1 b1 ..`) is the MASTER, and each solid node gets THREE mixed rows `u_s = Σ N_j(u_j + θ_j×d)` (linearized rigid plane-section arm, Abaqus shell-to-solid coupling TG §6.6.2/§6.6.6, kinematic/RBE2 flavor; frozen arm `d = x_s−x̄(ξ)` off a closed-form point-to-segment projection `ltProjectEdge` — no bucket-sort, no facet projection). Emitted through `ltEmitMixedRow` VERBATIM: its 1e-12 filter DROPS the θ·n (drilling) column since d ∥ shell normal ⇒ **drilling stays free** (Abaqus behavior; skew frames free via the null space of −[d]×). Tied DOFs FIXED to {1,2,3} (`-dof` refused) ⇒ BLOCKER-2 auto-satisfied by the solid's `-rho` — the P3 generator-level rotary-mass refusal is GONE (explicit projector still wants small master-edge rotary mass + a LUMPED-mass shell like `ASDShellQ4`, see [[LEDGER_quirks]]). Optional `-thickness t` arms an `|d| ≤ (0.5+tol)·t` guard (warn-if-omitted, OQ-3). Honest v1 limits GATED (oracle T6/T7): thickness Poisson stretch suppressed (∝ ν·t, exact ν=0), Timoshenko warping O(γ·t). Collocation-only (`-mortar`/`-hermite`/`-dual` refused — the weak form needs a kernel per-GP hook, deferred with mortar-Hermite); cross-ndf rows Transformation-INCOMPATIBLE ⇒ Lagrange/LadrunoProjection. Curl `θ=½∇×u` and shell-slave gradient rows both REJECTED at design (ADR-64 Decision 1). Oracle 22/22 + FE 18/18 (membrane/rigid/section/HEADLINE constant-moment-crosses-dissimilar-elements/hinge-contrast + 8 refusals + explicit dt_cr-neutral/zero-violation/momentum kick–coast). **ADR-78 (quadratic mortar facets, 2026-08-04, [[78_ladruno_quadratic_mortar_tie_adr]])** = quad8 slave/master + tri6 MASTER facets for `-mortar`/`-dual` (hex20 faces — the apeGmsh ADR 0086 D2 "both" follow-up): ALL geometry stays on the CORNER polygon (aux plane / clip / isomap / projection — the shipped, gated paths), only the basis evaluation changes (`shapeFull` serendipity at the mapped GPs) — exact under the midside-at-midpoint guard, and a curved/distorted quadratic facet is kernel status **-2**, a NAMED hard error, never a silent skip; degree-6 12-pt Dunavant rule for quadratic pairs (linear pairs keep order 4). Guards UNIFIED sign-free for ALL orders (sign-off OQ-2): per-facet AREA coverage + per-facet L1 gap (`∫|g_N|/area`) replace the per-node rowsum guards (quad8 corner row-sums are NEGATIVE, −A/12, by construction; the dual-mass refusal went sign-aware `|Ddual|`) — a deliberate behaviour change for linear decks (cancelling gap fields now refuse; P/weights byte-identical). tri6 SLAVES refused by name in BOTH bases (corner ∫N = 0 ⇒ dual scaling divides by zero — structural); hex20 slave surfaces need HRZ lumped mass (`LadrunoBrick20 -lumped`, ADR-35; the mass refusal hints this).
