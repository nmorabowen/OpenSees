| **Quadratic path-loss diagnosis** ([[82_quadratic_path_loss_diagnosis]]) — MEASUREMENT/DIAGNOSIS answering note 81 §5.5's open question, *why* quadratic elements lose the Newton path before their mechanism forms. **SCOPE BLOCKAGE, stated first: the fork owns NO 27-node hex.** `LadrunoBrick20` is 20-node serendipity (`std` = 3×3×3, `uri` = 2×2×2 per `LadrunoBrick20.h:41-44,157-158`); every "27" in `SRC/element/brick/` is a Gauss-point count (`Twenty_Node_Brick.h:158-161`); `ELE_TAG_TwentySevenNodeBrick 45` is a RESERVED tag with **no implementing class** (`grep -rn "class TwentySevenNodeBrick" SRC/` is empty — only four recorder type-maps pointing it at a placeholder `POLY_VERTEX`). So H27 was NOT run and nothing here substitutes for it. Reuses `h20_prandtl.py`'s mesh/consistent-Q8-surcharge/controls by IMPORT and the merged R3 gate's three-clause capacity rule. **Two new instruments, each calibrated before use:** the ported mobilisation field (every GP, not just point 1) with **control M0** — which fired immediately, showing `h20_prandtl.py`'s printed `m0` DROPS the `√(2/3)σ_y` apex term and is 2.9 % off as a field reference; against the exact form the field agrees to 2.6e-14 — and the **isochoric span ratio χ = 1 + ΔV/(A_foot·ds)**, an EXACT volume balance (base fixed, sides rollered, `u_y=0` everywhere ⇒ the only volume flux is through the free surface, integrated with the CONSISTENT weights). **Control CHI** calibrates it two-sided on elastic pushes: χ(ν→½) = +0.995, χ(ν=0) = −3.90, monotone; the operating ν = 0.45 elastic value is **−0.883**, which is the per-leg ZERO of the mechanism index **M = (χ−χ_el)/(1−χ_el)**. **Reproduces note 81 / gate #722 independently** (0.9977 / 1.0849 / 0.7713 / 0.5894 / 0.6846, deltas 0.00–0.70 %). **RESULT 1 — the span hypothesis is REFUTED.** Re-running the LINEAR control stopped at exactly the settlement where the quadratic dies: at s/B = 0.0112 (h0=1.0) H8 M = **0.803** vs H20 `uri` M = **0.788**; at s/B ≈ 0.0103 (h0=0.5) **0.784** vs **0.781** — agreeing to 0.4 %. The quadratic's mechanism is at the SAME stage of formation as the element that goes on to the exact answer. **This also corrects note 81 §5.1's "the split falls on ORDER":** the linear hex is itself hardening at **11.86 %** of initial at s/B = 0.0103, inside the "10–27 % quadratic signature" band, and then runs 7× further to a 0.004 % tail. The band is what the curve looks like at s/B ≈ 0.01 for EVERY element. **RESULT 2 — the wall MOVES on the controller's allowance and NOT on the algorithm; and it is NOT REPRODUCIBLE.** Lowering the floor 2e-7→2e-9 m alone (6.64→13.29 halvings) + budget 200→800 moved the leg further and higher in **both** repeats (2/2), while a genuinely different algorithm ladder at fixed allowance moved it **+0.06 %**. **But a REPEAT of the loose leg, identical in every argument, read 0.6951 / reach 0.01051 against the first run's 0.7306 / 0.01205 — a 5.1 % capacity and 14.7 % reach spread between BIT-IDENTICAL CONFIGURATIONS** (threaded-PARDISO FP nondeterminism amplified without limit by the adaptive controller — the mechanism the R3 gate's own ±3 % band justification names). So the allowance effect's DIRECTION is established and its MAGNITUDE is **not resolved by this design** (+1.5 to +6.7 %); the "+6.7 %/+19.4 %" of a single pair must not be quoted. The headline is over-determined either way and in fact strengthened: **no quadratic figure on this problem is a ceiling, and none is stable to three digits** — quoting 0.6846 / 0.6951 / 0.7306 / 0.7713 / 0.5894 as element properties is indefensible regardless of what the allowance does.
