| **LadrunoMassCache** — shared per-instance element mass-matrix cache (the ADR-77 G2 brick pattern factored into a reusable header). `lookup()` guard-compares the element-supplied signature (per-GP material rho — mutable via `setParameter "rho"` — + rho override + thickness) and nodal `getCrds()` on EVERY call, so invariance is checked, never assumed (ADR-76 App. A.4); miss/mismatch ⇒ the element forms exactly as before + `fill()` stores a byte-copy. Consumers: `BezierTet10` (64-GP Duffy consistent mass — the fork's most expensive formation), `BezierTri6`, `LadrunoQuad`, `LadrunoLST`, `LadrunoSolidShell` (brick idiom verbatim; `addInertiaLoadToUnbalance` routed); each exposes `-noMassCache` (transient, unserialized — T7 policy). All five previously returned class-static scratch — five more ADR-75b §5.4 shared-static hazards retired on the cached path. NOT applied: `LadrunoCST`/`LadrunoCSTPair` (trivial formation — guard ≈ win), `LadrunoUP` (mixed u-p mass inputs need their own review), `LadrunoBrick20` (already rho-signature-cached, F-1 #583); `LadrunoBrick` keeps its bespoke ADR-77 implementation. **Two rollout bugs found+fixed by layered testing** (§6i of [[77a_c0_t0_results_2026-07-26]]): brace-less-`if` zero-mass corruption (A/B-invisible; LST Zone-A eigen gate caught it) and the Quad/LST bare `this->getMass();`-for-side-effect contract that a cache hit invalidates (dynamics Rayleigh gate caught it; callers now consume the returned reference). 129/129 fork-solid batteries + 6/6 acceptance (`g2_mass_cache_ext_verify.py`, incl. setNodeCoord coords-guard liveness through the shared helper). **ADR-77 review wave (2026-07-27, 5-lens adversarial × 5 integrations + helper): no serial-run-corrupting bug found; hardening applied** — recvSelf now invalidates the cache in all 6 cache-bearing elements (sig-exempt construction-fixed inputs — massType/quadz/formulation/cMass — CAN flip on a restore-into-live-object with rho+coords unchanged ⇒ pre-fix a guard hit served the pre-recv mass; brick donor had the same gap), helper `lookup`/`fill` now tolerate null node pointers (warm cache + `setDomain(0)` removal flows / pre-setDomain getMass segfaulted where the uncached formation survived), helper contract now states the guarantee scope (bit-identity with the element's own formation, NOT geometric freshness for setDomain-snapshot elements: controlPts/X/SSP-J), the hit-pointer dangling caveat, and the serial-only `-noMassCache` escape;
