| **SolidTransformation** — geometry-method layer for solid elements (the solid analogue of beam `CrdTransf`/`CorotCrdTransf`, which are frames-only upstream). Decouples element *kinematics* (linear ⊂ corot ⊂ finite) from the constitutive/integration core, orthogonal to the *formulation* axis (std/bbar/uri/ssp). Corrected division of labour: the **formulation owns B-construction**; the transformation owns only `getStrainMeasure()`, `localizeDisp` (seam 2), `globalizeForce`/`globalizeStiff` (seam 3, +K_geo), and the recorder frame (`frameTimeVarying`/`getCurrentFrame`). **v1 = `SolidTransformationLinear` (identity)**: all seams are guarded no-op pass-throughs, so routing a small-strain element through it is bit-for-bit the direct kernel — that equivalence IS the seam proof. **Consumed by [[09_ladruno_brick]] `LadrunoBrick`** (holds `theGeom=new SolidTransformationLinear()`; calls `update`→`localizeDisp` for strain, routes `resid`/`stiff` through `globalize*`; serializes a method-id int in `idData(28)` as `+1000*methodID`, Linear=0 ⇒ byte-identical stream; rebuilds via `SolidTransformation::create()` in `recvSelf`). Element-agnostic — touches **no** `classTags.h` entry; **not a MovableObject** in v1. **corot (v2) IMPLEMENTED + green (PR #88):** element-level EICR — `R=polar(H)` (Procrustes best-fit of the nodal cloud, scaled Higham Newton), de-rotated small strain fed to the REUSED small-strain material lib (`ElasticIsotropic`/`J2Plasticity`, no finite material), exact residual `f=Rf_d−(1/n)RΣf_d−Γᵀm` + symmetric geometric tangent `R̄k_dR̄ᵀ+(G1+G1ᵀ)` (two O(strain) terms — polar-Hessian + material-∂R coupling — deferred to v2.1; residual exact ⇒ Newton converges regardless). Stateless (R from geometry; continuum nodes have no rotational DOFs); `std`+`bbar` only (`uri`/`ssp` parse-guarded off). **`SolidTransformationCorot` `MAX_NODES` raised 8→10 (allocation-only — all corot logic runs on the runtime `n`/`ndof`; the 8-node LadrunoBrick is unaffected) to admit a 2nd consumer, [[09_ladruno_brick]]'s tet sibling `BezierTet10 -geom corot` (plan `14_bezier_tet10_corot.md`).** Spin map Γ is SPATIAL (`Γ=R·ω_body`, `ω_body=(tr(S)I−S)⁻¹·2·axial(skew(RᵀδH))`). Validated: standalone Γ-vs-FD (caught a body→spatial frame bug pre-build) + 8-lens adversarial-review workflow (39 findings/**33 confirmed/6 refuted**; core math re-derived & confirmed correct) + 14 Zone-A tests incl. rigid-rotation>π, FD-tangent-gap-vanishes, **ADR Gate 5 load-driven cantilever** (matches `-geom finite` <1% at ~26% tip deflection) & **Gate 6 J2-plasticity-in-rotated-frame**. **v1 linear MERGED (PR #71).** **v3 `SolidTransformationFinite` IMPLEMENTED (updated-Lagrangian):** `getStrainMeasure()==DeformationGradient`; the element computes `F=I+Σuⱼ⊗∇ₓNⱼ` per GP, calls `FiniteStrainNDMaterial::setTrialF(F)`, assembles `∫Bᵀσ dv` + the consistent tangent `K_{(a,i)(b,k)}=∫ ∂Nₐ/∂xⱼ a_ijkl ∂N_b/∂xₗ dv` with `a_ijkl=c_ijkl−σ_il δ_jk` (full-gradient contraction; localize/globalize identity since the element owns the whole UL assembly). **KEY contract revision: `c=(1/2J)[D:L:B]` is NOT minor-symmetric in (k,l), so it CANNOT pass through a 6×6 — the material now exposes the FULL 4th-order tensor via `FiniteStrainNDMaterial::getSpatialTangentTensor(c[3][3][3][3])`; the old `getTangent` 6×6 is a lossy projection.** v3 scope: `-geom finite` + `-formulation {std\|bbar}` (uri/ssp+finite reserved). **`bbar`+`finite` = F-bar (dSNPO §15.1, the large-strain volumetric-locking cure):** the element drives the material with the modified gradient `F̄=(detF₀/detF)^(1/3)F` (F₀ at the centroid; `updateFinite`), residual unchanged (eq 15.9 — only σ̄ changes), and the consistent tangent gains the eq 15.10 coupling `∫Gᵀq(G₀−G)dv` with `q=(1/3)a:(I⊗I)−(2/3)σ̄⊗I` (eq 15.11, full `a=c−σδ` — **NOT** the material `c` alone; a naïve spatial shortcut drops the `−(2/3)σ⊗I`). This term is **generally UNSYMMETRIC** ⇒ needs `FullGeneral` (logged in [[LEDGER_quirks]]). Locked against the primary source (de Souza Neto, Perić & Owen 2008 Ch.15) after a 3-derivation adversarial workflow disagreed (all 3 reproduced the shortcut's wrong `(1/3)c` coefficient). Verified: FD consistent-tangent + symmetry + homogeneous-deformation patch + rigid-rotation objectivity + reduce-to-linear (std, 6/6 green); **F-bar: FD-tangent (unsymmetric-aware) + reduce-to-std-on-homogeneous-F + T4 volumetric-locking cantilever (std locks at ν→0.5, F-bar doesn't)**.
