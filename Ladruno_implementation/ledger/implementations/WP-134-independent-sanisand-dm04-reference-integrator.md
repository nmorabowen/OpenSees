| **WP-134 — independent SANISAND (DM04) reference integrator, the oracle for TIMs F18 / WP-128 / WP-129** ([[134_sanisand_reference_integrator]]). Pure Python (numpy + scipy), written from Dafalias & Manzari (2004), not from `ManzariDafalias.cpp` or WP-128's `md_port.py` (the C++ was read only to list the UW additions). The DM04 rate equations are integrated as a stiff ODE in pseudo-time over one increment (SciPy Radau, rtol 1e-10). Events end each smooth segment: yield, unloading, the loading-denominator sign, the α_in reversal (paper rule: α_in := α at every plastic onset with (α−α_in):n < 0, so h ≥ 0 by construction), the Macaulay kinks, and p → p_floor. The regularised exact form of L and hL at (α−α_in):n = 0 needs no h cap. N > 0 with H ≤ 0 STOPS as `H_nonpositive`, never mapped to elastic. Mixed stress/strain control drivers cover triaxial and simple shear. The UW additions are separate toggles U1–U9 (D_factor sigmoid, p_r, p_min, G(e_init), e-law(e_init), once-per-increment α_in rule, h cap, frozen Ce, and **U9: ModifiedEuler never recomputes K, G inside the increment**), with presets `uw` (RK45), `uw_me` (ModifiedEuler) and `uw_model` (UW constitution + paper integration = the WP-129 target). C++ cross-check through WP-127's `ladrunoSANISANDReplay` in a CPython-3.12 subprocess (read-only).
