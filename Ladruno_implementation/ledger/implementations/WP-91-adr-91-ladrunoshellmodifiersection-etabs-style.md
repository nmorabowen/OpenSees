| **ADR-91 `LadrunoShellModifierSection` -- ETABS-style shell stiffness modifiers** ([[91_ladruno_shell_stiffness_modifiers_adr]]) -- a decorator `SectionForceDeformation` that wraps ANY order-8 plate/shell section (response codes exactly `{FXX,FYY,FXY,MXX,MYY,MXY,VXZ,VYZ}`, e.g. `ElasticMembranePlateSection`/`MembranePlateFiberSection`) and applies nine independent modifiers (`f11,f22,f12,m11,m22,m12,v13,v23,mass`, all default 1.0; deliberately no aggregate/weight modifier) via the SPD-preserving congruence `D' = S*D*S`, `S = diag(sqrt(f11..v23))`, applied identically to strain (`eIn = S*e`), stress (`sigma = S*sigma_in`), consistent tangent and initial tangent -- exact and energy-consistent for an arbitrary (possibly nonlinear) inner section, unlike a diagonal-only rescale (which can drive the membrane block indefinite when a small f11/f22 meets an unscaled Poisson coupling term). `mass` scales `getRho()` only. Named refusals in the OPS_/Tcl factory: inner order != 8, inner response codes not exactly the plate set, any modifier < 0, inner section tag not found; a modifier == 0.0 is allowed (ETABS parity) but warns once (per instance) naming the singular mode. `commitState`/`revertToLastCommit`/`revertToStart`/`getType`/`getOrder`/`setParameter` forward to the inner section; `sendSelf`/`recvSelf` ship the 9 modifiers plus the inner section's classTag/dbTag (`ParallelSection` nested-section pattern) and re-fetch it from the broker on receive. DDM sensitivity intentionally NOT implemented (base-class defaults apply) -- out of scope for WP-91.
