| **LadrunoModalResponse** ([[44_ladruno_frequency_domain_adr]], umbrella [[45_ladruno_modal_family_roadmap_adr]]) — modal-superposition frequency/response-domain toolkit. **P1a `modalResponseHistory`** = the EXACT piecewise-linear (Nigam–Jennings / first-order-hold) modal-superposition transient. After `eigen`+`modalProperties`, each retained mode is a decoupled SDOF `q''+d q'+ω²q=f(t)` (d=c/m) advanced by a constant per-mode recurrence `[q₁;q̇₁]=A[q₀;q̇₀]+B[f₀;f₁]` exact for a load linear within the step; physical response recovered `u=Σ(φ·Vscale)q` (+ vel/accel) and ONE domain step COMMITTED per time station so ordinary recorders capture the history exactly as a direct run. Excitation (P1a): uniform base accel, relative form, modal load `f=−Γ·ü_g` with Γ = `modalProperties` participation factor — recovery is the time-generalization of `ResponseSpectrumAnalysis::solveMode` (inherits its mass-normalization + pressure-DOF skip; never touches m_α). **KEY DESIGN: (ω,d) parametrization not (ω,ξ)** — unifies under/critical/over-damped by the discriminant `Δ=ω²−(d/2)²` AND covers a rigid-body mode carrying Rayleigh mass-damping (ω=0, d=a0>0) that a `q''=f` rigid branch silently drops; the load block is a **branch-uniform particular+homogeneous decomposition** (`q_p=(f0+rt)/ω²−dr/ω⁴`, cancel-at-rest, propagate by A) NOT the fragile hand-expanded Chopra tables. Damping channels: `-damp ξ` / `-rayleigh a0 a1` (`d=a0+a1ω²`) / `-modalDamp ξ₁ ξ₂ …`; optional `-modes` subset, `-t0`. Per-step commit = `setCurrentDomainTime(t)`→`updateDomain()` (no applyLoad ⇒ no stray load patterns)→`commitDomain()`. Gates: closed form vs a van-Loan `expm` first-order-hold oracle ~1e-14 across all branches incl rigid-Rayleigh (compiled g++ cross-check, `modal_response_p1a_spike/`); SDOF end-to-end vs numpy exact-PWL @1e-9 (3 branches); multi-mode vs OpenSees Newmark (alphaM) @2e-3 + vs an INDEPENDENT numpy full-matrix Newmark of (M,a0M+a1K,K) @1e-3; the C++ transient matches a numpy full-modal-superposition to 1e-18. **P1b `responseSpectrumAnalysis -combine`** = native modal-combination stage (the parity gap stock Petracca RSA leaves to the user): opt-in `-combine {SRSS\|CQC\|ABS\|TenPercent}` (+ `-damp`/`-modalDamp` for CQC ζ) combines per-mode peak nodal DISPLACEMENTS into ONE committed field; `-combine` absent ⇒ byte-identical to stock. CQC = Der Kiureghian ρ_ij, Ten-Percent = RG-1.92; novel math isolated in the header-only stamped kernel `LadrunoModalCombination.h` (cross-checked to machine precision vs numpy incl ρ=0.523@r=1.1,ζ=0.05 + identical→ABS / separated→SRSS limits), RSA edit = thin additive wiring (`analyzeCombined()`). CAVEAT: combination is per-quantity & nonlinear — v1 combines displacements only. **P2 `frequencyResponse` / `steadyStateDynamics`** = modal frequency-response / steady-state dynamics. For a harmonic base accel `ü_g=amp·e^{iΩt}` the steady relative response is the small dense modal sum `û(Ω)=amp·Σ(ψ_a)(−Γ_a)H_a(Ω)`, `H_a=1/(ω_a²−Ω²+iΩd_a)` — the frequency-domain image of P1a's recovery (same ψ_a=φ·Vscale + Γ_a, inheriting P1a's validated normalization; ONE per-mode complex evaluation, no time stepping). `frequencyResponse` returns the full complex FRF `{f,Re,Im}` per (node,dof); `steadyStateDynamics` returns the harmonic amplitude `{f,|·|}`. Frequencies in **Hz** (Ω=2πf); grids `-lin`/`-log`/`-biased` (resonance-clustered ±5% around each in-band ω_a/2π); `-resp disp|vel|accel` (relative; ×1 / ×iΩ / ×−Ω²); `-amp`, `-modes`, `-out` + table returned via `OPS_SetDoubleListsOutput`. New free class `LadrunoFrequencyResponse` + shared `LadrunoModalDamping` struct in the same file; two `OPS_*` entries share a parser. **Sign convention PINNED e^{+iΩt}** (−90° response lag at resonance). Gates: OpenSees FRF (Rayleigh) vs an INDEPENDENT numpy DIRECT complex solve `(K−Ω²M+iΩC)⁻¹(−MR)` @1e-8 across disp/vel/accel (pins sign+normalization+H-form end-to-end, NOT reusing the modal formula); SDOF |H| peak 1/(2ξω²) + +90° phase + static limit; FRF magnitude peaks at ω_a (`-biased`); SSD Ω→0 == `|K⁻¹MR|`; SSD==|FRF|; rayleigh==modalDamp; uniform-ξ vs numpy modal; log/biased grid shape; 7 guards. **P3 `randomResponse`** = stationary random response (PSD→RMS). Input = **ONE-SIDED base-accel PSD `G(f)` in Hz** ((accel)²/Hz; `σ_üg²=∫G df` — the engineering-spec convention; vs the textbook two-sided rad/s PSD, `G(f)=4π·S(Ω)`), supplied as a `timeSeries` sampled at `f` (`-inputPSD $tsTag`, e.g. Path f→G points or Constant). Response auto-PSD **rides the P2-validated FRF unchanged**: a new slim `LadrunoRandomResponse` class internally drives `LadrunoFrequencyResponse::run()` (zero touches to the validated P2 lines — all shared validation inherited) and propagates `G_xx(f)=|H_x(f)|²G(f)`; band moments by trapezoid on the sweep grid `m_k=∫f^k G_xx df` → **RMS=√m0**, zero-upcrossing `ν0=√(m2/m0)` [Hz], Davenport expected peak `(√(2ln ν0T)+0.5772/√(2ln ν0T))·RMS` with `-duration T` (needs ν0T>1, warns otherwise). Returns scalar RMS; `-stats` → `{rms,ν0,m0,m2(,peak)}` via `OPS_SetDoubleOutput`; `-out` writes `{f,G_in,G_xx}` rows. Same `-lin/-log/-biased` grids (`-biased` is the documented recommendation: a 200-pt LIN grid mis-integrates a ξ=0.5% peak by ~14%, biased by 0.05%), `-resp disp\|vel\|accel`, `-modes`, damping channels. **Guards:** `nf≥2` (band integral needs measure — P2 allows nf=1, P3 refuses), `G(f)≥0` on the whole grid, **refuse a zero-damped mode whose resonance lies inside the band** (divergent variance integral; out-of-band undamped modes stay legal), and **refuse a rigid-body mode (ω=0) when f=0 is in-band for ANY damping** — its FRF diverges at its own f=0 even with Rayleigh a0>0 (**the Opus gate's MAJOR:** the d≤0 test alone waved the w=0/-rayleigh case through to a silent inf/NaN RMS; + gate MINOR fixed: `-duration` return shape is ALWAYS 5 entries, peak=NaN when ν0T≤1, never a runtime 4-vs-5 unpack surprise; unreliable-range warning for 1<ν0T<2). CONVENTION PINNED empirically (`modal_response_p3_spike/psd_rms_oracle.py`): white-noise SDOF anchor `σ_x²=G0/(8ξω³)` @2.9e-6, Monte-Carlo synthetic realization 0.6% (a one/two-sided bug reads ~41%=√2, Hz/rad ~150%=√(2π)), ν0 vs counted upcrossings 0.6%, exact-period synthesis trick (T=1/df ⇒ input variance exact). Gates: white-noise analytic; {f,Gin,Gxx} table + RMS vs an INDEPENDENT numpy direct complex solve `\|(K−Ω²M+iΩC)⁻¹(−MR)\|²G` row-for-row @1e-8 (disp/vel/accel); Monte-Carlo time-domain leg (exact PWL SDOF march, fixed seed) @8%; ν0≈fn narrow-band; σ_v=ω·σ_x; rayleigh==modalDamp; mode subset vs single-mode numpy; -out==return; zero-damp out-of-band legal + 7 refuse guards. **`-load` follow-up (P2/P3 nodal-force excitation)** = second excitation channel on `frequencyResponse`/`steadyStateDynamics`/`randomResponse`: `-load $patternTag` drives harmonic nodal forces `amp·P·e^{iΩt}` (FRF/SSD, ABSOLUTE response) or `P(t)=s(t)·P` with `-inputPSD` = one-sided PSD of the scalar `s(t)` (random, fully correlated). `P` = the pattern's plain `NodalLoad` reference values (pattern's own TimeSeries IGNORED). **Modal load `f_a=ψ_aᵀP/m̃_a`, `ψ=evec·Vscale`, `m̃_a=generalizedMasses()(a)` — normalization-invariant because DomainModalProperties applies -unorm scaling to V IN PLACE before computing GM/MPF** (pinned in `modal_response_p3_spike/load_frf_oracle.py` vs direct solve @1e-15 on a deliberately non-mass-normalized basis + the `-baseAccel == -load(P=−MR)` identity + white-force-PSD anchor `σ_u²=G_F/(8ξω³m²)`; end-to-end `-unorm` invariance test).
