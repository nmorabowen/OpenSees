| **ADR-85 T0 -- 2D contact declarations + rigid-plane acceptance** ([[85_ladruno_contact_2d_adr]] Sec.How/8, gate G-T0) -- the first phase of the 2D contact lane: it opens the DECLARATION surface to `-ndm 2` decks, pins the dimension oracle, and makes every 2D combination the engine does not yet support fail LOUDLY AND BY NAME. **(1) One oracle.** Dimension comes from the referenced nodes' `getCrds().Size()`, never from `OPS_GetNDM()` (interpreter ndm is mutable across repeated `model` commands without wiping the domain, has no ndm in {0,1} story, and resolves through an unguarded static `TclModelBuilder*` on the classic Tcl path). **(2) Declaration.** `contactSurface -master|-slave-segments 2` (a 2D LINE segment) is accepted iff every referenced node is 2D; a node set that MIXES `getCrds()` sizes is refused for ANY kind including `-slave`; `nps 3|4` still requires 3D nodes -- which is what preserves the old `>= 3` check's second job of keeping a 3D deck from declaring 2-node segments. `LadrunoContactDomain::addSurface`'s faceted-arity choke point widens `3..4` to `2..4` (the whole-number-of-segments invariant is unchanged). **(3) `contactPlane`.** The slave-surface lookup moves ahead of the numeric parse so the plane inherits the same oracle; a 2D surface accepts the ergonomic 7-arg `tag ssTag nx ny px py kn` AND the legacy zero-padded 9-arg form (which stays PERMANENTLY valid), disambiguated by counting the leading numeric run -- 5 => 2D, 7 => legacy, with `nz`/`pz` required to be exactly 0 on a 2D surface. **(4) Guards.** `ladrunoSurfaceNodesOk` becomes a dimension-CONSISTENCY pre-flight that reports the surface's common dimension instead of demanding 3D, a new `ladrunoContact2DLaneOk` sibling refuses a 2D surface on the NTS pair lane (`ADR-85 T1b`) and the mortar/tie lane (`ADR-85 T3`), and `ladrunoContactPairDimOk` gates the PAIR at all three shipped pre-flight call sites -- which is where an ARITY-FREE surface is first seen. That last one closes a hole review caught: the NTS slave is a `SLAVE_NODES` set with NO `nodesPerSeg`, so an arity-keyed check cannot see its dimension, and a 3D master paired with an all-2D slave node-set would have passed the relaxed pre-flight and fed 2D nodes to the 3D lane (where a `-ndm 2 -ndf 3` slave clears the `ndf != 3` guard and `getCrds()(2)` reads out of bounds -- the historical incident, reintroduced). A cross-dimension pair is now a named FATAL (`ADR-85 dimension`); it was previously impossible, since the shipped pre-flight refused every 2D surface, so no 3D deck reaches the branch. The per-surface gate checks the **`ndf == ndm == 2` EQUALITY contract first** (`ADR-85 ndf`), because a `-ndm 2 -ndf 3` frame node is a modelling error (`FE_Element::setID()` packs each node's full DOF_Group ID, so an extra DOF shifts every later `myID` slot) and must not be hidden behind a roadmap message. Refusing beats skipping: a silently dropped contact converges, balances its reactions and transmits nothing -- the ADR-78 P0 failure mode. **The RIGID_PLANE lane is untouched, and its `ndf >= ndm` rule is CORRECT, not an inconsistency.** The `ndf == ndm` equality contract is a MULTI-node-FE packing requirement: `FE_Element::setID()` (`FE_Element.cpp:283-292`) copies each DOF_Group's FULL ID sequentially into `myID`, so on an FE spanning several nodes one node with extra DOFs consumes extra slots and shifts every LATER node's slots -- silent mis-assembly. The rigid-plane adapter binds a SINGLE node, so there is no later node to shift: it deliberately keeps `ndf >= ndm` and couples that node's first ndm translational DOFs. Real decks rely on this today (a shell or beam node resting on a rigid plane in 3D), and the truncation is safe and reported -- `setID` copies the first ndm entries, which are ux, uy(, uz) in order, then emits the upstream `numDOF and number of dof at the DOF_Groups` warning and returns -3. Also untouched: the six shipped `getNumberDOF() != 3` sites (3D-only; T1b generalizes them). **3D byte-identity by construction:** every new check is either dimension-neutral or gated behind `dim == 2` / `nps == 2`, which no 3D deck reaches.
