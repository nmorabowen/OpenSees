| **WP-174 — GitHub issues are the shared memory** (protocol [Ladruno_internal/ISSUES.md](../../../Ladruno_internal/ISSUES.md), modelled on apeGmsh's program charter). Live state moves off private session memory onto GitHub: a WP's state and handoffs on its draft PR, a multi-WP program on a `program` issue, everything open on a pinned `board` issue, each out-of-scope finding in its own issue. Private memory keeps preferences and pointers only. Adds the AGENTS.md rule, the handoff/board/finding templates, labels `board`/`program`/`in-flight`/`blocked`/`human-gate`/`lesson`, and the issue forms `.github/ISSUE_TEMPLATE/{finding,program}.md`. | process + docs | — (no class tag) | `AGENTS.md`, `Ladruno_internal/ISSUES.md`, `.github/ISSUE_TEMPLATE/finding.md`, `.github/ISSUE_TEMPLATE/program.md` | draft | TBD |
