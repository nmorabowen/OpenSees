| **ADR-85 F1 -- `-outward winding`: the 2D NTS master chain declares its own side** ([[85_ladruno_contact_2d_adr]] Amendment F1, amending How/2 + How/8) -- a follow-on orientation mode on the shipped 2D NTS lane. `-outward` gains a third form, the keyword `winding`: the interface-level centroid vote is BYPASSED and `sigma` is fixed at **+1**, i.e. every master segment's normal is `perp(t) = (-t_y, t_x)` of ITS OWN travel direction -- the slave lies to the LEFT of the chain's traversal. **What it unlocks:** (a) FLUSH interfaces (coincident master/slave centroids -- the masonry joint, the footing on soil, every zero-gap deck this lane's headline applications name), which the vote refuses as DEGENERATE; (b) CLOSED-LOOP and strongly curved masters (a ring, a full indenter profile), which the vote refuses as SPLIT -- and refuses *even with* `-outward`, because no single direction vector agrees with every segment's own perpendicular, so before F1 there was no route at all. A closed loop already satisfied chain integrity (the `headSeg == (tailSeg + 1) % nSeg` wrap is explicitly legal), so the split vote was its sole blocker. **A parameterization, not a formulation.** `sigma` was already one scalar per interface and the kernel already evaluated `n = sigma*perp(t_k)/L_k` from segment k's own tangent (`LadrunoContact2DKernel::projectSegment2D`), so `LadrunoContact2DKernel.h`, `LadrunoContactFE`, the concave-vertex classifier, the D4 end-cap and `ladrunoResolveAutoKn2D` need **ZERO** edits -- three of them are sign-independent anyway (`ladrunoResolveAutoKn2D` reads only `n^T K n`, so sigma^2 = 1). **The guard that is not optional (the reason this is one PR and not two):** the handle()-time chain-integrity scan is VACUOUS for a DISJOINT master (`if (v.size() <= 1) continue;` skips every node used exactly once), and a disjoint master is legal and documented. The SPLIT-VOTE refusal is what actually catches a mis-wound second run; bypassing the vote would have turned that named FATAL into a silent wrong-side normal (ADR-78 P0). So winding carries its own ONE-CONNECTED-CHAIN requirement, refused by name -- given the scan, exactly one consecutive-adjacency pass (`mTags(2k+1) == mTags(2k+2)`), necessary and sufficient, O(nSeg), satisfied by open chains, single segments and closed loops alike. See [[LEDGER_quirks]]. **Scope fence:** NTS only. The 2D mortar lane runs no chain scan, so the invariant is not established there and hoisting the scan would newly FATAL permuted/reversed mortar masters that ship ACCEPTED today -- a shipped-lane behavior change owed its own ADR decision. Winding + `-mortar` is a named refusal; **flush MORTAR interfaces still abort** and mortar users still pass `-outward ox oy`. **WIRE-FORMAT BREAK:** one new NTS field means `LCD_FMT_VERSION 2 -> 3` and `LCD_NTS_SLOTS 21 -> 22` (`LadrunoContactDomain.cpp`), per the in-source protocol; a stored v2 definitions stream (an ADR-78 P2 database, or a pre-F1 MPI peer) now draws the named version refusal. Same class as T3's 1 -> 2 bump. **Disclosed, not fixed (two):** (1) winding moves the 'does the master FACE its slave' check to the caller -- the centroid vote was also catching that, and under winding such a deck runs and produces a converged wrong answer (pinned as a fact by the sign-flip row's DISARM leg; the declaring layer above should own the check); (2) a CLOSED LOOP with facets coarse relative to its own diameter transmits EXACTLY ZERO -- measured n <= 8 inert / n >= 9 exact for a unit-circumradius regular n-gon at the default `-cell`, attributed to the broad-phase grid cap (`NX*NY*NZ <= nSeg`) failing to separate the ring's far side, after which the ordered-ownership deferral cycles around the closed chain with no starting point. Both in [[LEDGER_quirks]]; the second is PINNED by a labelled limitation test.
