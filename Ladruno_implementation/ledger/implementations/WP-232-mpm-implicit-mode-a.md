| **WP-232f — MPM mode A, ADR 232 phase 1** ([[232_ladruno_mpm_general_driver_adr]] §5.3, [[232_ladruno_mpm_guide]]; frozen interface `tests/mpm_implicit_interface.md`) — implicit dynamic and quasi-static MPM through the user's own analysis. `mpm mode implicit|quasiStatic` makes every particle a `LadrunoMPMPoint` element (`ELE_TAG_LadrunoMPMPoint = 33026`, not user-creatable) whose nodes are its active uGIMP support at the step-start position, re-pointed in place every step; the active support nodes are Domain nodes (fresh tags, a retired tag never reused, W5; empty support excluded by the mass cutoff — mode-A default 1e-6 — or ghost-regularized for M0b). Per step: P2G (disp 0, projected v, a) onto the nodes, grid conditions as the host pattern's `SP_Constraint`s (`mpm fix`, `mpm gridvel` prescribed velocity with `start` / `track`), an unconditional C++ `Domain::domainChange()`, then `DirectIntegrationAnalysis::analyzeStep(dt)` (Newmark / HHT / GeneralizedAlpha only) or `StaticAnalysis::analyze(1,false)` under `LoadControl` (Δλ = dt, the user's increment restored after). Kinematics through `hypoIncrementFromF` / `…PlaneStrain` on the reset grid; LadrunoBrick's hypo assembly at one point (material + geometric term; new `pushTangentPlaneStrain`); lumped mass; alphaM / betaK Rayleigh. G2P is batched at the last particle element's `commitState()` (FLIP increments with `mpm flip`), skipped when a commit refusal is pending (particles unmoved, W17). A step failing before commit is cut and retried (`mpm cut`, no regrowth); one failing after a commit began aborts. Two analysis bridges: classic Tcl (`commands.cpp` globals) and the DL engines (`OPS_LadrunoMPMDL`, `cmds`). Database save / restore admitted in mode A (host and element `sendSelf` / `recvSelf`, broker entries); mode F still refuses. Commands: `mode`, `gridvel`, `condForce`, `pforce`, `emptyNodes`, `cut`, `tagBase`, `rayleigh`, `info g2p|acceptedSteps|retries|dtHistory|domainChanges|connectivityChanges|gridNodes|gridNodeTags|mode`, `debug failAttempt|reseed`.
