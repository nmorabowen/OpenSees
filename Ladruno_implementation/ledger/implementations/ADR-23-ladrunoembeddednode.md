UR / UP / D9 / `-corot` are KEPT but EXPERIMENTAL (flag-gated, NOT validated): UR = `½curl(u)` SPIN not moment transfer (CST/TET4 → rigid spin); UP = niche poromechanics; D9 = interface/contact-flavored (LadrunoContact/LadrunoBondSlip lineage), uncoupled friction only approximate. Must-fix before D9 promotion: `getInitialStiff` per-direction INITIAL tangent (no `setTrialStrain` side effect); + retroactive sendSelf version field.** **Isotropic sibling of `LadrunoEmbeddedRebar`** sharing `LadrunoEmbeddedKernel` (ADR 23 Phase 0): same penalty/AL + `-k auto` + bipenalty machinery, but `D_u = K_u·I` (no bar axis, no axial/transverse split, no bond-slip; the isotropic tie is already frame-objective ⇒ the U/UP/UR **penalty** tie needs **no `-corot`** — LEDGER_quirk; `-corot` exists only for the D9 **material** frame, v2 below). Reads the host cartesian gradients `∂N_i/∂x` via a NEW vanilla `Element::getInterpolationGradients(ξ,dNdx)` (default −1; overridden on `LadrunoBrick` via `shp3d` + `BezierTet10` via `computeJacobian`) — supplied explicitly with `-dNdx` (the gradient analog of `-shape`, any host), queried with `-gradXi ξ..`, or auto-queried by `-xi` on a gradient-capable host. `g_r=θ_c−θ_host`, `t_r=K_r·g_r` (+`λ_r` AL), `D_r=K_r·I`; the rotation `B`-block (cNode rot → +I, host trans → −½skew(∇N_i)) scattered to the cNode rotation slots (disjoint from U/UP). `K_r` via `-kr` (numeric) or `-kr auto`=`krAlpha·K_u·lch²` (first `getCharacteristicLength()` call in the family; needs `-host`). **Activated only if the cNode carries rotation DOFs** (ndf≥ndm+nrot: 3D→6, 2D→3) else degrades to no-UR (warn). **M5/D7-1 parse guard: `-rot` and `-pressure` mutually exclusive** (2D ndf=3 ambiguity). **M1/ES-1 per-DOF-class bipenalty**: rotational inertia `I_p=K_r·(dt/2)²` lumped on the cNode rotation DOFs (same budget as `m_p` but with `K_r` ⇒ `dt_r=dt_u`; a translational-only `m_p` can't bound the rotation mode).
