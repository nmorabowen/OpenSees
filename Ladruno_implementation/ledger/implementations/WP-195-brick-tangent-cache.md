| **WP-195 (item 1) — stdBrick element tangent cache** ([[195_ladruno_brick_tangent_cache_adr]]). WP-192's 3C profile: stdBrick was 54 % of element time (tangent 63 µs per element per call) because it re-formed its 24x24 stiffness (8 Gauss points x 8 x 8 B^T D B products) at every tangent call, although the Paper 1 soil is `ElasticIsotropic` (rev3 3C / 4D material 21). **What ships:** `Brick::getTangentStiff()` forms the residual with the uncached code (`formResidAndTangent(0)`), fetches the eight material tangents, and compares their RAW BITS and the nodal coordinates' bits (`memcmp`) with those that built the cached stiffness; equal => the cached matrix (bit-identical by construction: same inputs, same code), otherwise the stiffness is rebuilt by the same loop nest and re-cached. Elasticity is observed through the material, never assumed (no class flag: a material `updateParameter` reaches the material, not the element). Explicitly invalidated by `revertToStart`, `setDomain`, `setDamping`, `setParameter`, `updateParameter`, `recvSelf`; off with a Damping object; gives up (frees) after 16 consecutive misses until `revertToStart`; 4.9 KB per element (uniform D) / 6.9 KB (per-point D); `LADRUNO_BRICK_TANGENT_CACHE=0` at construction disables it; element response `ladrunoTangentCache` = [enabled, state, hits, builds, misses]. **Verified:** rev3 3C serial window (Pardiso, MKL 1 thread, 12 gravity increments + 5 steps, every node every step at 17 digits) cache on == cache off == the WP-192 base binary, byte for byte; `tests/test_wp195_brick_tangent_cache.py` (elastic static + transient, yielding J2, `updateParameter` and `setParameter -ele` routes, `setNodeCoord`, `reset`; full-field md5, cache on == off); mutation (hit ignores the D bits) killed by 3 of them. **Measured:** see the ADR §4 (3C rev3 window, 2 ranks).
