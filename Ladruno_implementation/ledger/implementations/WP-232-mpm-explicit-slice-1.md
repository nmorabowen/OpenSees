| **WP-232c — explicit MPM, slice 1** ([[232_ladruno_mpm_general_driver_adr]], [[232_ladruno_mpm_guide]]) — the native explicit Material Point Method engine (ADR 232 mode F) hosted as a `LoadPattern` subclass (`LadrunoMPMPattern`, `PATTERN_TAG_LadrunoMPM = 33027`) and driven by one `mpm` command row (`grid`, `body` lattice seeding, `particle`, `velocity`, `stress`, `fix`, `wall`, `gravity`, `timeSeries`, `damping local`, `flip`, `massCutoff`, `safety`, `criticalTimeStep`, `analyze`, `reset`, `info`, `particleData`, `debug` hooks). Numerics in the OpenSees-free `LadrunoMPMCore.h`: uGIMP (interface A2 centre admissibility; A5 ghost node layers beyond every face, nothing dropped) and linear hat, MUSL with PIC/FLIP blend, relative mass cutoff, FLAC local damping, `h/(c+|v|)` critical-Δt refusal, grid-face fixes and a stationary Coulomb wall; the kinematics go through the new `hypoIncrementFromF` / `hypoIncrementFromFPlaneStrain` entry of `LadrunoHypoKernel.h`. Admitted particle materials: `ElasticIsotropic`, `LadrunoJ2` (not `-autoRegularization`), `DruckerPrager` (`materialState` through `parameter … loadPattern`); refusals for everything else, free FE DOFs, database save, OpenSeesSP / MP. Phase c2, the 232a contracts: `mpm particles -file` reads a Contract-1 particle set all or nothing with every C1 rule and the engine refusals (unequal cell sizes, a grid other than the deck's, initial stress on a non-elastic material, an id met in the epoch); `mpm output` writes the `.ladruno` particle group (FORMAT_VERSION 1, FORMAT_MINOR_VERSION 2 only on particle files; particle-only stages written as the recorder's empty stage; KIND transient, MODE explicit; PARTICLE_EPOCH bumped by `mpm reset`; int64 ids; NULLTERM strings), with int64 / string-array / empty dataset writers added to `Ladruno_Hdf5.h`.
