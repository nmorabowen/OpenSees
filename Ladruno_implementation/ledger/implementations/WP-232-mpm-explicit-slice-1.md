| **WP-232c — explicit MPM, slice 1** ([[232_ladruno_mpm_general_driver_adr]], [[232_ladruno_mpm_guide]]) — the native explicit Material Point Method engine (ADR 232 mode F) hosted as a `LoadPattern` subclass (`LadrunoMPMPattern`, `PATTERN_TAG_LadrunoMPM = 33027`) and driven by one `mpm` command row (`grid`, `body` lattice seeding, `particle`, `velocity`, `stress`, `fix`, `wall`, `gravity`, `timeSeries`, `damping local`, `flip`, `massCutoff`, `safety`, `criticalTimeStep`, `analyze`, `reset`, `info`, `particleData`, `debug` hooks). Numerics in the OpenSees-free `LadrunoMPMCore.h`: uGIMP (interface A2 centre admissibility; A5 ghost node layers beyond every face, nothing dropped) and linear hat, MUSL with PIC/FLIP blend, relative mass cutoff, FLAC local damping, `h/(c+|v|)` critical-Δt refusal, grid-face fixes and a stationary Coulomb wall; the kinematics go through the new `hypoIncrementFromF` / `hypoIncrementFromFPlaneStrain` entry of `LadrunoHypoKernel.h`.
