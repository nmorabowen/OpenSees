| **Consistent mass-scaling PARALLEL PCG (V5)** ([[38_ladruno_consistent_mass_scaling_adr]], mass-scaling handoff §0 "V5") — makes the CONSISTENT (Olovsson) path correct under OpenSeesMP (`system MPIDiagonal`). The serial `consistentPCG` is rank-local (local dot products, no shared-DOF `M̄` exchange) ⇒ wrong at partition boundaries. V5 adds a **distributed PCG** keyed on one ownership-free weight `wᵢ=1/multiplicityᵢ`: the matvec applies the (global, replicated) lumped diagonal WEIGHTED + off-diagonal `M̄ₑ` in FULL, then sum-assembles shared DOFs across ranks (diagonal collapses to full-once, off-diagonal accumulates); global inner products use the same weight + all-reduce; all CG control scalars are global ⇒ identical iteration count on every rank ⇒ collectives stay in lockstep (no deadlock). Collapses byte-identically to the serial PCG at `np=1`. The 3 consistent integrators live in the shared `OpenSeesLIB` and must NOT reference the MP-only `MPIDiagonalSOE` ⇒ runtime dispatch through 4 new `LinearSOE` base virtuals (serial no-op defaults; `MPIDiagonalSOE` overrides). Shared `refineAccel` body factored into `LadrunoConsistentRefine.h`.
