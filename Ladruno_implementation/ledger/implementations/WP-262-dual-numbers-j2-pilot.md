| **WP-262 — `LadrunoDual.h`: dual numbers (forward-mode automatic differentiation), J2 pilot** — Header-only `ladruno_dual::Dual<N, S = double>`: a value plus N derivative directions in a fixed array (no heap, the Sacado SFad model), nestable (`Dual<N, Dual<M>>` for second derivatives), C++17, OpenSees-free, no implicit conversion to double. Arithmetic, mixed Dual/scalar operators (spelled out: template deduction never applies the converting constructor), value-based comparisons, `sqrt exp log pow sin cos fabs fmax fmin` found by ADL, `value()` (identity on double) and `zero_value()` (for the implicit-function-theorem step). The value part of a Dual run follows the double operations exactly. **Pilot:** `LadrunoHardening.h` (`yieldStressVoceLinear` / `yieldSlopeVoceLinear`) and the undamaged J2 return map are written once as templates: `returnMapT<T>` with `plasticResidual<T>` shared by the scalar Newton and, for a Dual T only (`if constexpr`), one final Newton step with its value zeroed, so the derivative is the IFT derivative at the converged point and the value stays bit-identical. `returnMap()` keeps its signature and calls `returnMapT<double>`; every caller is unchanged. **Gates:** the six existing J2 kernel C++ checks print byte-identical output against the pre-WP headers (g++ `-O2`, `%.17g`); `tests/test_ladrunoJ2_dual_tangent_cpp.py` (7 paths, 42 steps, 37 plastic): analytic `Dtan` = `Dual<6>` tangent to ≤ 1e-12 relative (measured ~1e-16, worst 2.8e-14) where the FD gate resolves ~1e-11 at best; value part bit-identical at every step; break-the-gate leg: a symmetrized `Dtan` fails on the non-proportional Armstrong–Frederick path. `returnMapDamaged` (Lemaitre) and `Params` stay double in this WP.
