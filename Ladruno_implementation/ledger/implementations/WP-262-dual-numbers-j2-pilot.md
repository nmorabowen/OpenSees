| **WP-262 — `LadrunoDual.h`: dual numbers (forward-mode automatic differentiation), J2 family** — Header-only `ladruno_dual::Dual<N, S = double>`: a value plus N derivative directions in a fixed array (no heap, the Sacado SFad model), nestable (`Dual<N, Dual<M>>` for second derivatives), C++17, OpenSees-free, no implicit conversion to double. Arithmetic, mixed Dual/scalar operators (spelled out: template deduction never applies the converting constructor), value-based comparisons, `sqrt exp log pow sin cos fabs fmax fmin` found by ADL, `value()` (identity on double) and `zero_value()` (the implicit-function-theorem step). The value part of a Dual run follows the double operations exactly. **(1) J2 kernels templated on the scalar:** `LadrunoHardening.h` (strain scalar T and constant scalar P), `LadrunoDamage.h`, and in `LadrunoJ2Kernel.h` `returnMapT<T>` / `returnMapDamagedT<T>`, with `plasticResidual<T>` shared by the scalar Newton and, for a Dual T only (`if constexpr`), one value-zeroed Newton step at the converged point, so the derivative does not lag the value (quirk). `returnMap()` / `returnMapDamaged()` keep their signatures; every caller is unchanged. **(2) `LadrunoUniaxialJ2` return map extracted** into `SRC/material/uniaxial/LadrunoUniaxialJ2Kernel.h` (`returnMap<T, P>`, `ParamsT`, `StateT`); `setTrialStrain` is its double instantiation. **(3) `LadrunoUniaxialJ2` DDM:** `getStressSensitivity`, `getTangentSensitivity`, `getInitialTangentSensitivity`, `commitSensitivity`, each one `Dual<1>` pass. The pass seeds the active parameter (E, sig0, Qinf, b, Hiso) and the committed history sensitivities (`SHV`: εᵖ, p̄, D, ΔD, X_k per gradient), plus the strain gradient at commit. This closes the silent `dσ/dθ = 0` of this fork fiber in DDM-capable beams (quirk). **Gates:** (a) the six pre-existing J2 kernel C++ checks print byte-identical output against the pre-WP headers (g++ `-O2`, `%.17g`); (b) `tests/test_ladrunoJ2_dual_tangent_cpp.py` (12 paths, 5 of them Lemaitre with D up to 0.85 and one IMPL-EX): analytic `Dtan` = `Dual<6>` tangent to ≤ 1e-12 (measured ~1e-16, worst 2.8e-14), value part bit-identical, a symmetrized `Dtan` flagged on the non-proportional AF path; (c) `tests/test_ladrunoUniaxialJ2_dual_cpp.py`: the kernel is bit-identical to a verbatim transcription of the pre-WP `setTrialStrain` (72 steps, 6 materials incl. damage / IMPL-EX / sig0 = 0); dual tangent = analytic to 4e-14; DDM propagated through history = FD of the whole path to 1e-9–1e-12 for 5 parameters; dropping the history sensitivities fails; (d) `tests/test_ladrunoUniaxialJ2_ddm_fiber.py`: a cyclic fiber-section `dispBeamColumn` cantilever (response 1.21× the elastic one both ways), `sensNodeDisp` = FD of the run at 3.0e-10 (sig0), 7.5e-10 (E), 2.8e-8 (Hiso), the same as the Steel01 control with its hand-coded DDM (2.3e-10, 2.7e-10); (e) MSVC `build.bat` green, J2 / UniaxialJ2 binary tests pass. **Not in this WP:** nD `LadrunoJ2` sensitivities (no NDMaterial DDM consumer for its modes), damage-constant and `lchRef` sensitivities, `SHV` in `sendSelf`.
