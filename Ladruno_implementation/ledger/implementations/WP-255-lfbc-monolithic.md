| **WP-255 — `element LadrunoForceBeamColumn … -monolithic`** ([[200_ladruno_frame_elements_apegmsh_emitter_guide]] §2.3; ADR `255_lfbc_monolithic_solve.md`; MCFT shear-critical fibre-beam program #1131, after WP-254) — An opt-in state determination for `LadrunoForceBeamColumn3d` that solves all section deformations and the basic forces together, `x = (e_1..e_n, q)`, with one Newton on the section tangents `K_s`: section rows `(s_i(e_i) - b_i q - s_p,i)/sc`, compatibility `(Σ w_i L b_iᵀ e_i + v_sh + v_T - v)/sc_c`, Model C's scales (force rows 1e5, moment rows 1e8, compatibility 1e-5, the axial row as a mean strain), LAPACK `dgesv`, a backtracking line search (`-monoHalve`, 12 halvings, sufficient decrease `1 - 1e-4 λ`), `-monolithic [maxIter tol]` (40, 1e-5). No section is ever inverted (the nested loop needs `f_s = K_s⁻¹`, which does not exist once every strip and bar of a section is on a flat branch after a shear failure); only the whole block matrix must be regular. Element tangent `dq/dv` from the same LU with six right-hand sides. `-monoAccept aF aM [aC]` Model C's acceptance of a stagnated solve (off; the lab uses 10 kN / 10 kN m); `-monoRestart 0|1` (default 1) retries a failed solve from the committed state, Model C's start rule, which picks Model C's branch at the shear failure; `-monoStall n [ratio]` (off) early exit; `-monoScale`; parameters `monoRestart`, `monoStall`; `eleResponse monoStats`. `revertToLastCommit` skips `getSectionFlexibility` in this mode; refused with `-hinge*` and `-axialRelease`. Default nested path unchanged. Gates: `tests/test_ladrunoForceBeamColumn3d_monolithic.py` (14: monolithic = nested to 1e-6 on a cyclic biaxial Concrete02/Steel02 fibre column with aggregated shear and axial load, elastic `-shear` closed form to 1e-9, symmetric tangent, parser, `monoStats`), the 130 existing LFBC tests; lab battery (Sezen & Moehle 2002, Lynn et al. 1996) with Model C's driver and calibration: 8/8 complete (WP-254's column stopped on 4), lab score J 0.149 vs Model C 0.155.
