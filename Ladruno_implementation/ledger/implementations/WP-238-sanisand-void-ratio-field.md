| **WP-238 — a heterogeneous initial void ratio for LadrunoSANISAND: per-element `voidRatio` and a correlated field generator** ([[238_sanisand_void_ratio_field]]; [[LadrunoSANISAND_implex_guide]] §14). The imperfection route to localisation, as done with strength fields in concrete, put on the quantity that varies in a sand bed. (1) `Ladruno_scripts/sanisand_void_ratio_field.py`: a truncated Gaussian field as a FUNCTION OF POSITION (random Fourier modes drawn from the seed; `gaussian` or `markov` correlation with a scale of fluctuation per axis), so two meshes sample one realisation and refinement resolves it; numpy only; `apply(ops, ele_tags, values)`. (2) `setParameter -val e -ele tag voidRatio` on `LadrunoSANISAND`: the untagged element form of vanilla's `voidRatio` parameter was a SILENT NO-OP (the base registers it only with a material tag); it is now claimed, validated (finite, > 0), refused for a point with strain history in the plastic stage, and at a strain-free point the initial elastic operator is rebuilt, so the point is bit-identical to one constructed with that void ratio. No vanilla file is touched.
