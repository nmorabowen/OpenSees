| **Build-entry-point unification** — one way to compile the fork. `Ladruno_scripts/build.bat` gains an `installer` verb that chains `build_inno_installer.ps1` after a successful full build, so `build.bat clean installer` is the whole release recipe; its argument parser now scans the full arg list for the verbs `clean`/`rebuild`/`installer` (previously `clean`/`rebuild` were first-arg-only) and **refuses** `installer` alongside explicit targets, because `build.bat` refreshes `dist\` only for the targets it built and a 4-of-5 build drops `dist\openseesmp` entirely — packaging that produces a normal-looking `setup.exe` carrying a MIXED install. Legacy peer packager `Ladruno_scripts/make_installer.ps1` (zip + generated `install.ps1` + ps2exe wrap) **deleted**: no artifact of its shape has shipped since the Inno wizard landed (`Ladruno_files/` holds only `*_setup.exe`), and it read as a peer of `build_inno_installer.ps1`. New `Ladruno_scripts/README.md` maps every script to its role; `CLAUDE.md` gains a *Building — there is exactly ONE way* section (always-loaded, which is where the guidance was missing). Upstream's competing recipes deleted per [[LEDGER_vanilla_files]]. **Also fixes a long-standing `build.bat` defect found by actually running the build:** the MUMPS "build once" guard was dead, because the unescaped `)` in its own banner line `echo === Step 1: Building MUMPS 5.5.1 (one-time, ~15-20 min) ===` closed the enclosing `if not exist (` block — so MUMPS was reconfigured/rebuilt on EVERY build and seeding `mumps-install/` per BUILD_GOTCHAS section 6 did nothing. Parens escaped; verified by re-running the same command and watching Step 1 skip. See new BUILD_GOTCHAS section 10b. `build_inno_installer.ps1`'s closing line also stopped advertising the deleted packager's `install.ps1 + .zip` as "available". | tooling/docs | — | `Ladruno_scripts/build.bat`, `Ladruno_scripts/README.md` (new), `CLAUDE.md`, `BUILDING.md`, `Ladruno_internal/01_compilation_journal.md`, `Ladruno_implementation/01_inno_setup_installer.md`; deleted `Ladruno_scripts/make_installer.ps1` | shipped | wp/build-scripts-unify |
