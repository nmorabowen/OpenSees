| **LadrunoDynamicRelaxation** — quasi-static solver by **explicit, matrix-free dynamic relaxation** (the explicit sibling of LadrunoArcLength): fictitious-mass leap-frog + **Cundall kinetic damping** driven to static rest, under the stock `DirectIntegrationAnalysis` driver with `algorithm Linear` + `system Diagonal` (NO analysis-core surgery). **`M*` = integrator-owned Gershgorin row-sum fictitious mass** (`m_i=(dt²/4)Σ_j|K_ij|`, scale-free; built once in `domainChanged` via an SOE-free element-stiffness probe), assembled onto the diagonal SOE by an overridden `formTangent()` so the solve degenerates to a `M*⁻¹` apply — deliberately NOT `getMass()` (zero on zero-density models, the ADR-20 BLOCKER). Modes `-mass {gershgorin\|lumped\|unity}`. True static residual `‖f_ext−f_int‖=‖M*·a‖` (no `f_v` pollution). Termination is **script-owned** via `Ladruno_scripts/relax_to_static.py` (velocity+displacement decay; the stock transient driver has no convergence early-exit). Differentiates from `ExplicitDifferenceStatic` (33001, user-tuned Rayleigh) by auto-tuning everything — the LS-DYNA `*CONTROL_DYNAMIC_RELAXATION` sibling Abaqus lacks. ~70% leap-frog reuse from CentralDifferenceLadruno. **v2 (same PR): `-damping viscous` (viscous-critical mode, lagged-velocity, `cVisc=4ζs/dt` with `s=√(1+ζ²)−ζ` so the explicit damping stays stable) + auto-refresh (`M*` rebuilt at each kinetic-energy peak where velocities are already zero ⇒ snap-through is stable with NO manual `-recompute`).**  **Classic-Tcl registration (#729):** the `ladrunoDR` command answered only under `TclWrapper`/`PythonWrapper` and was absent from `SRC/tcl/commands.cpp`, so `OpenSees.exe` and `OpenSeesMP` got `invalid command name` for it — a `.tcl` deck could START a relaxation but never read the settling gate that says when it is done. Registered there; the subcommand dispatch moved verbatim into the header-only `SRC/analysis/integrator/LadrunoSolverQuery.h` so BOTH engines share one copy, and the classic bridge passes `commands.cpp`'s own integrator global in (the no-arg `OPS_Ladruno*Cmd()` form reads the DL-engine-only `cmds` singleton and would have returned SUCCESS with an EMPTY result). Deferred v3: per-region KE zeroing.
