| **WP-182 — relativeMassDamping** ([[RelativeMassDamping_guide]]) — mass-proportional Rayleigh damping relative to a prescribed reference velocity, `f_D = alphaM M (v - v_ref(t))`, for absolute-coordinate SSI models (removes the `alphaM M v_ff` drag towards the fixed frame). `relativeMassDamping <tag> -vel <dof> <tsTag> ... (-region ...|-node ...|-allMassNodes)` attaches a time-only reference (copied TimeSeries, cache keyed on the domain time) to nodes with nodal mass and returns the audit `nAttached nAlphaZero Σ αM·m_dof`. Residual only — `Node::getDamp` and the tangent unchanged; reactions flag 0/2 and `getResponse(RayleighForces)` return the relative force; EnergyBalance books `v^T C (v - v_ref)` in `DW_nod` (closure exact) and `-v2 -relativeMassSplit` adds advisory `DW_rel` (>= 0) and `W_ref` columns. Integrators that form the nodal damping through `DOF_Group::addD_Force` (`*_TP`, sensitivity branches) are refused (FATAL, `_Exit`). Every edit guarded by `massDampingRef == 0` with the original statement in the unguarded branch: models without the command are byte-identical.
