| **WP-168 — `Ladruno_registerCommands` command hook** (apeGmsh#1490, panel P9 R10; KC5 prerequisite for the K3 loader). The 30 fork-only interpreter commands (contact family, `ladrunoBuild`/`ladrunoThreads`/`ladrunoMutation`/`ladrunoSANISANDReplay`, `profiler`, `ladrunoNumbering`, the ADR-52 trial probes, `ladrunoArcLength`/`ladrunoDR`/`ladrunoLoadControl`, `LadrunoStaggeredAnalyze`, `criticalTimeStep`, `complexEigen`, the ADR-44 modal family, `LadrunoTie`, `ladrunoProjectionTieForce`) are rows of ONE X-macro table, `SRC/interpreter/LadrunoCommandTable.h` (`LADRUNO_COMMAND(name, dl, classic)`), and each engine registers them with ONE call: classic Tcl `Ladruno_registerCommands(interp)` (commands.cpp: OpenSees/SP/MP), DL Tcl `Ladruno_registerCommands(this, interp)` (TclWrapper.cpp), Python `Ladruno_registerCommands(this)` (PythonWrapper.cpp: opensees.pyd / openseesmp.pyd). The DL bridges are generated per row (template on the `OPS_*` entry point; same shape as the 29+29 hand-written `Tcl_ops_*`/`Py_ops_*` bridges, which are deleted); classic Tcl keeps its own bridges (several bind engine state: `theStaticIntegrator`/`theTransientIntegrator`, #729) and the table names them. Each column expands only in its own TU, so no DL entry point reaches the classic link. No command changed name or behaviour. Recorded gaps (`LADRUNO_NONE`): classic Tcl lacks `ladrunoProjectionTieForce`, `LadrunoTie`, `ladrunoTrialResidualNorm`, `ladrunoSetNodeTrial`, `ladrunoLoadControl`, `criticalTimeStep`, `complexEigen`; the DL engines lack `ladrunoNumbering`. Gates: `tests/test_ladruno_command_registry.py` (zone_a: every row present AND every gap absent in the classic exe via `info commands` and in the Python module via `hasattr`; `ladrunoBuild` smoke; runs `ci/check_ladruno_commands.py` on the tree), `ci/check_ladruno_commands.py` (H1 a table/Ladruno-named/`// Ladruno`-marked command registered outside the hook, H2 an engine not calling the hook exactly once, H3 a malformed table; self-test `ci/test_check_ladruno_commands.py`). | interpreter infrastructure | — (no class tag) | `SRC/interpreter/LadrunoCommandTable.h` (new), `SRC/interpreter/LadrunoCommandsTclWrapper.h` (new), `SRC/interpreter/LadrunoCommandsPython.h` (new), `SRC/tcl/LadrunoCommandsClassicTcl.h` (new), `SRC/tcl/commands.cpp`, `SRC/interpreter/TclWrapper.cpp`, `SRC/interpreter/PythonWrapper.cpp`, `Ladruno_scripts/stamp_headers.py` (GLOBS), `ci/check_ladruno_commands.py` (new), `ci/test_check_ladruno_commands.py` (new), `tests/test_ladruno_command_registry.py` (new) | draft PR open | — |
