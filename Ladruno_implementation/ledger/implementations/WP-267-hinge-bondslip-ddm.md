| **WP-267 (D-SENS2) — DDM sensitivities by dual numbers, `LadrunoCohesiveHinge` + `LadrunoBondSlip`** — The WP-262 `LadrunoUniaxialJ2` recipe ported to two more fork uniaxials that inherited the silent `dσ/dθ = 0` stubs. **(1) Kernels extracted, templated on the scalar** (`T` state, `P` constants): `LadrunoCohesiveHingeKernel.h` (`computeDerived` calibration with the guarded penalty floor, `pmMultiplier` for the parabolic and `-pmBal` laws, `envelope`, `trialState` incl. IMPL-EX with the frozen step ratio as an input) and `LadrunoBondSlipKernel.h` (`setDerived`, MC2010 `envelope` / `envelopeTangent`, friction-slider `trialState`; a kernel-local `powT` gives `pow(Dual, Dual)` for the exponent α). The classes call the double instantiations; every caller unchanged. **(2) DDM:** `getStressSensitivity`, `getTangentSensitivity`, `getInitialTangentSensitivity`, `commitSensitivity`, each one `Dual<1>` pass seeded on the active parameter and the stored history sensitivities (`SHV`, copied in `getCopy`, cleared in `revertToStart`): hinge `[κmax, κmax_old]` (κmax_old feeds the IMPL-EX extrapolation), bond-slip `[Cslip, Cstress, CslipMaxAbs]`. The derived constants are re-derived in Dual the way `updateParameter` re-derives them (default Kpen = r·Mc²/(2Gf); Gf overriding s3), so the DDM is the derivative of `updateParameter` + the run. Hinge parameters: Mc, Gf, Kpen, P0, alphaPM, P0t, Pbal, muBal (`setParameter` now also sets the value). Bond-slip: `setParameter` / `updateParameter` are new (tau_max s1 s2 s3 tau_f alpha Gf s0). A defaulted s0 (= 0.1·s1, none given) now keeps following s1 on `updateParameter` and in the DDM (`s0User` flag; no existing value changes); before the fix the first MSVC run of the binary test missed on s1 by 4.4e-1 (quirk `WP-267-defaulted-constant-frozen-by-derive`). **Gates (g++ -O2, header-only):** (a) `tests/test_ladrunoCohesiveHinge_dual_cpp.py`: kernel = verbatim transcription of the pre-WP class bit for bit (8 hinges × 12 cyclic steps, calibration incl. the floor clamp, both P-M laws, IMPL-EX STEP and PSEUDO); reported tangent = dual jump derivative to ≤ 3e-18·Kpen; DDM through history = FD of the whole path for 36 (case, parameter) pairs, worst 2.1e-8; dropping the history sensitivities misses by ≥ 1.47e-3; (b) `tests/test_ladrunoBondSlip_dual_cpp.py`: bit-identical on 4 backbones × 14 steps visiting all seven branches; tangent consistent on envelope and unload (≤ 4e-17) and the deliberate k0 / −1e-12·k0 pivot guard pinned on the plateau, residual and slider; DDM = FD for 28 pairs (α included), worst 1.2e-9; NOHIST misses by ≥ 4.1e-4. **Binary tests (orchestrator, after the build):** `tests/test_ladrunoCohesiveHinge_ddm.py`, `tests/test_ladrunoBondSlip_ddm.py`: zeroLength springs in parallel with an elastic one under cyclic load control, `sensNodeDisp` vs FD of the run (tol 1e-5), each with a Steel01 control leg (the harness and Steel01 legs pass on the pre-WP binary; the FD is step-size-stable to ≤ 7e-8). **Not in this WP:** `LadrunoRebarBuckling` (WP-264 owns it), `LadrunoCohesiveHingeBiaxial` (nD), the P_axial sensitivity of a P-M hinge (the parent beam's), `SHV` in `sendSelf`.
