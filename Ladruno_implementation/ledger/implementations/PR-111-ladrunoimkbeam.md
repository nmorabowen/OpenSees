| **LadrunoIMKBeam** — 3D concentrated-plasticity beam-column macro element with **uncoupled** moment-rotation IMK rotational hinges (one independent uniaxial law per bending axis, per end). Built to dodge the rigid-diaphragm spurious-axial-`P` failure of fiber-hinge `forceBeamColumn`+`HingeRadau` (fiber hinge couples P-M → contaminated moment capacity + fragile solver). **Displacement-driven stiffness formulation**: basic 6×6 `[N,Mz_i,Mz_j,My_i,My_j,T]`, exact series `F = F_elastic + F_hinge` (**no n-factor** — that was a two-element-Python-recipe hack), each bending axis a tiny **2×2 internal Newton** on hinge rotations (`θ_h = v − F_el·M(θ_h)`, `J = I + F_el·diag(k_t)`); softening `k_t<0` resolved at element level. **Material-agnostic** — takes pre-built `uniaxialMaterial` moment-rotation tags (`-matZ`/`-matY`, `-hinge both\|i\|j`; **per-end asymmetric `-matZi`/`-matZj`/`-matYi`/`-matYj`** override the symmetric law and are independent of `-hinge`), so steel (`IMKBilin`/`Bilin`) and concrete (`ModIMKPeakOriented`/pinching) differ only by tag, and the two beam ends can carry different deteriorated backbones. Column-face offset + geometric NL delegated to `CrdTransf3d` (`geomTransf -jntOffset`). Exact `getInitialStiff` (clean initial-stiffness Rayleigh; no inflated stiffness → Zareian-Medina βK pathology absent). Single-tag recorders: `basicForce`/`basicDeformation`/`hingeRotation`/`hingeMoment` + `material <0-3>` passthrough. **NON-goals (v1):** no P-M, no biaxial My-Mz coupling (block-diagonal — future `LadrunoIMKColumn`); no element distributed loads (`-mass` lumped only). (Asymmetric end laws SHIPPED, see status.) Mechanics also reachable vanilla via `forceBeamColumn`+`HingeRadau`+`section Aggregator{IMK Mz, IMK My, Elastic P, Elastic T}` — this is a usability/robustness packaging. **2D COMPANION `LadrunoIMKBeam2d` (classTag 33004):** planar reduction — basic 3×3 `[N,Mz_i,Mz_j]`, strong-axis only (`-matZ`/`-matZi`/`-matZj`, no `-matY`; input `A E Iz transfTag`). The per-axis hinge solve (2×2 internal Newton + flexibility condensation) is extracted **verbatim** into header-only `LadrunoIMKHinge.h` (`ladrunoIMKSolveAxis`/`ladrunoIMKInitBlock`, OpenSees-free) shared by BOTH classes — 3D calls it twice (Mz/My), 2D once (Mz); the 3D refactor to call it is bit-identical (same Zone-A battery green). **ndm-dispatch:** the single `LadrunoIMKBeam` command builds 2D or 3D from the model dimension (ndm 2/ndf 3 → 2D, ndm 3/ndf 6 → 3D), same UX as `elasticBeamColumn` (no separate command).
