| **InitDefGradNDMaterial** (`nDMaterial InitDefGrad`) — multiplicative, finite-strain staged-activation wrapper: the large-strain sibling of `InitStrainNDMaterial`. Makes a finite-strain continuum element **born stress-free at the deformed geometry** when appended mid-stage (staged construction). Wraps an inner `FiniteStrainNDMaterial` (e.g. `LogStrain`) and **IS-A** `FiniteStrainNDMaterial`, so `LadrunoBrick -geom finite` (and any future F-based solid) consumes it with **zero element edits** (passes the element's `dynamic_cast<FiniteStrainNDMaterial*>`). At activation it captures the **birth deformation gradient `F0`** and thereafter forwards the **relative** gradient `F_rel = F·F0⁻¹` to the inner — the multiplicative split `F = F_rel·F0` (Lee). **OBJECTIVE** where the additive `InitStrain` offset is not: under a post-birth rigid rotation `F→Q·F`, `F_rel→Q·F_rel` so `C_rel=F_relᵀF_rel` is unchanged ⇒ zero spurious stress (subtracting `u0` gives `F_naive=F−F0+I=Q·F0−F0+I≠I`). **KEY simplification — the shipped seam is SPATIAL, not PK1:** (1) the incremental gradient `F_Δ=F_rel·F_rel,n⁻¹=F·F_n⁻¹` is **invariant to `F0`** (F0 only sets the stress-free initial state, never the step response); (2) the inner returns true **Cauchy σ** (reference-independent), so **no `P=P_rel·F0⁻ᵀ` push-back and no `J0` integration weight** are needed (the element already integrates `∫bᵀσ dv` on the current config with its own `det F`; the inner's `getJ()=J_rel=det F/det F0` is unused by assembly) — the (PK1-dialect) design note's energy-consistency bookkeeping is **subsumed**. So the wrapper is a near pass-through: capture `F0` once, forward `F_rel`, delegate stress/tangent/state. **Trigger = AUTO-CAPTURE on the first `setTrialF`** (= the birth gradient, since `addElement→setDomain→update` evaluates at the committed deformed state; each mid-stage append gets a fresh wrapper ⇒ multi-lift falls out free) — Truss `initialDisp` lifted to a full 3×3. Opt-out `-noInitF` (pass-through ≡ bare inner); explicit `-F0 f11..f33` for a known birth; `setResponse("F0")` reports the captured gradient. Degenerates to identity at `t=0` (`F0=I`). For **small-strain** elements the additive `InitStrain` offset is still correct + cheaper — this earns its keep only on `-geom finite`.
