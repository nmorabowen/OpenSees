| **LadrunoEmbeddedRebar** — embedded-reinforcement **coupling** element ([[20_ladruno_embedded_reinforcement_adr]], **v2 slice 2**) tying one rebar node to a host solid element's nodes via precomputed shape-function weights `N_i`, so a rebar mesh embeds in a **non-matching** concrete mesh. Pure coupling (bond) — the rebar's own axial stiffness lives on a separate `corotTruss`/beam along the bar. External nodes `[rebar, host_1..host_M]`; gap `g = u_rebar − Σ N_i u_host_i` decomposed along the bar axis `dir` into axial slip `s` + transverse `g_t`; traction `t = F_axial(s)·dir + kt·g_t`, `F_axial` = perfect (`kAxial·s`) or bond (`LadrunoBondSlip` σ(s)·`bondScale`, `bondScale=perimeter·L_trib`). `P = Bᵀt`, `K = BᵀDB`, `D = (dF/ds)·dir⊗dir + kt·(I−dir⊗dir)` (anisotropic, D6). **MODE P** (penalty) — implicit + explicit (adds stiffness only). **MODE T (transformation/DOF-elim) DEFERRED:** the perfect-bond `u_rebar=ΣN_i u_host_i` needs a **multi-retained** constraint the stock single-retained `MP_Constraint` can't express (a separate larger lift — recorded). Host-agnostic (weights precomputed by the apeGmsh generator); rebar element type (truss\|beam, D6) is the user's choice on the rebar mesh. Parse `element LadrunoEmbeddedRebar tag rebarNode {nHost h1..hN \| -host eleTag} {-shape N1..NN \| -xi x1..x_ndm} -dir dx dy dz (-bond matTag [-bondScale bs] \| -perfect kAxial) [-kt {kt\|auto}] [-ktAlpha a] [-corot {-xiB.. \| -shapeB..}] [-enforce {penalty\|al}] [-bipenalty {-dtcr dt \| -wcap β}]`; setResponse `slip`/`bondStress`/`axialForce`/`force` + `kt`/`penaltyEnergy`/`constraintViolation`/`bondEnergy`/`dir`/`augLambda`/`gap`/`mpenalty`/`dtcr`. **§10 Mode-P roadmap (ADR 20):** `-host`/`-xi` host-query forms (#175); `-kt auto` host-stiffness-scaled penalty + energy/diagnostic responses (#177); `-corot` co-rotated bar axis lifting the small-rotation limit (#180); `-enforce penalty\|al` augmented-Lagrangian kernel (per-step Uzawa, gap→0 at moderate kt; bond-slip axial untouched) (#181). **`-bipenalty` (§10.6, build-order item 5):** mass penalty `m_p` lumped on the rebar node so the explicit `dt_cr` of the GLOBALLY assembled system (host carries real mass) is BOUNDED + reported via `eleResponse "dtcr"`. `k_eff=max(k_axial,kt)`; two budgets `-dtcr dt` (`m_p=k_eff(dt/2)²`, no host) / `-wcap β` (`m_p=k_eff/(β·ω_host)²`, `ω_host=√(‖K_host‖/‖M_host‖)`). Lumped-on-slave keeps M diagonal (DiagonalSOE-safe); element refuses Rayleigh factors (no spurious dt shrink); gated on `-enforce penalty` (AL⇒`m_p=0`). Default OFF⇒mass≡0, bit-identical. **Adversarial-review correction:** bipenalty does NOT make the element visible to the per-element `CriticalTimeStep` EIGENSOLVE (that BC/host-mass-blind problem sees this coupling element as `λ_max=0` — the massless free host slaves out the constraint). **§10.6.1 seam (SHIPPED):** a vanilla `virtual double Element::getExplicitCriticalTimeStep()` (default −1) folded into `CriticalTimeStep`'s per-element loop carries the element's self-reported `2√(m_p/k_eff)` into the running min (skipping the eigensolve for it), so `ops.criticalTimeStep`/`-cflAbort` now honor the embedded bound. Vanilla `Element.{h,cpp}` + `CriticalTimeStep.cpp` edits ([[LEDGER_vanilla_files]]).
