| **WP-185 — `ladrunoSchema` v0, v1** (apeGmsh#1667, program link F3; consumed by apeGmsh `BackendInfo` in F4). One new interpreter command, in classic Tcl and in the DL engines (TclWrapper, Python), returning ONE JSON string, compact and key-sorted at every level, with no paths or timestamps: `{"build": <ladrunoBuild>, "commands": [sorted rows of LadrunoCommandTable.h this engine registers], "engine": "dl"\|"classic", "options": {<owner>: {<token>: {"nargs": n\|"list", "since": "<PR/WP>"}}}, "schema_version": 0}`. Everything is generated: `commands` from the X-macro table (columns stringified, so no entry point is referenced and one header serves both the classic and the DL link), `options` from the new `ladruno_opt::kOptTables` registry in `SRC/material/LadrunoOptSpec.h` (one row per fail-closed parser: owner name + table; today `LadrunoRCConcrete` and `LadrunoRCFiniteStrain` on `kLadrunoRCOptions`). Fail closed: any argument is refused (Tcl error / Python exception), and a duplicate command, owner or token makes the command fail rather than emit ambiguous JSON. Gate: `tests/test_wp185_ladruno_schema.py` (zone_a: exact JSON round-trip, `build == ladrunoBuild`, `commands` == the table's rows per engine, `options` == the header declarations, pinned `since` anchors, bad arguments raise in both engines, and every `ladruno_opt::reportUnknown` call site's (name, table) pair has a `kOptTables` row). **v1 follow-up (apeGmsh#2517, [#1017](https://github.com/nmorabowen/OpenSees/pull/1017)):** a new top-level `capabilities` list, sorted, generated from `ladruno_schema::kCapabilities` in `LadrunoSchema.h` (duplicate refused): behavioural facts no command or option token shows. First entry `mdStageFlagPreserved` = no ManzariDafalias / LadrunoSANISAND constructor resets the class-wide `mElastFlag` (fix 43b235bbb, #1005, apeGmsh#2444). `schema_version` 0 -> 1 because v0's key set was closed in both readers (this test and apeGmsh `BackendInfo`); from v1 a new row in an existing section does not bump the version, a new section does. Gate: `tests/test_md_stage_flag_capability.py` + `tests/tcl/md_stage_flag_capability.tcl` (listed AND kept: a full-constructor instance after the stage-1 flip leaves uz equal to the flip-only leg, rel 1e-9, 17 % from elastic; mutation-tested by reintroducing the reset in the full constructors; plus a source tripwire that no constructor of the nine-class ManzariDafalias / LadrunoSANISAND family writes `mElastFlag`, the only check that reaches the classTag constructor, mutation-tested with a classTag-only reset).
