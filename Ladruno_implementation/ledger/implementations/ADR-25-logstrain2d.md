| **LogStrain2D** — 2D (plane) Hencky/log-strain finite-strain adaptor (2×2 **F**), the plane sibling of [[09_finite_strain_material_wrapper]]'s `LogStrainNDMaterial` (33010). **P5 decision (2026-07-09): shipped as a NEW class (33016), NOT getType views of 33010** — the 3D `FiniteStrainNDMaterial` seam is rigidly 3D (`setTrialF` 3×3, order 6, "ThreeDimensional"), so a 2D face needs its own contract; a chameleon `dimMode` on the shipped-and-verified 3D class would risk regressing it. LogStrain2D presents an order-3 PlaneStrain/PlaneStress face over a 3D order-6 inner by **composing** an internal `LogStrainNDMaterial` (reuses the verified MATISU kernel + bᵉ state + plastic protocol VERBATIM): **plane strain** lifts the element's 2×2 F to 3×3 with F₃₃=1 (the full 3×3 bᵉ is carried, so plastic ε₃₃≠0 from deviatoric J2 flow is tracked exactly — plane strain IS the 3D problem with F₃₃=1) and reads back the in-plane block; **plane stress** solves the thickness stretch λ=F₃₃ from σ₃₃=0 by a local Newton (FD dσ₃₃/dλ, warm-started from committed λ) then statically condenses the out-of-plane direction from the spatial tangent (δσ₃₃=0) for the consistent 2D modulus (dSNPO §14.7; elastic λ recovers ε₃₃=−ν/(1−ν)(ε₁₁+ε₂₂)). New fork-local base `FiniteStrainND2DMaterial` (2×2 `setTrialF`, order-3 face, `getSpatialTangentTensor2D(c[2][2][2][2])`) locks the ADR-25 P5 element seam; parser `nDMaterial LogStrain2D $tag $innerTag <-planeStrain\|-planeStress>` (default plane strain); `getCopy("PlaneStrain"/"PlaneStress")` re-modes on element request. Seam contract mirrors 3D: `getStress()`=in-plane Cauchy σ {11,22,12}, element forms a=c−σ_il δ_jk. **MATERIAL-ONLY this PR** (verified building-free: numpy oracle `tests/logstrain2d_reference.py` reproduces textbook plane-strain/plane-stress elastic matrices + closed-form λ + objectivity + plastic ε₃₃; C++-kernel-vs-oracle `tests/test_logstrain2d_kernel_cpp.py` diffs σ + full 16-comp c₂ to 1e-9 incl degeneracy; openseespy construction gate `tests/test_logstrain2d.py`). **Opus adversarial gate: math/composed-state-cycle/serialization/getCopy/getInitialTangent all confirmed correct; 3 robustness fixes applied** — (1) guard the plane-stress condensation pivot a₂₂₂₂→0 (refuse-loudly, else a near-perfectly-plastic inner NaN-poisons the element tangent), (2) Newton residual now tested on the final-update iterate (was an off-by-one that could falsely report non-convergence), (3) `revertToLastCommit` resets the trial λ (defense-in-depth). Element `-geom finite` wiring (LadrunoQuad/CST P5 + 2D SolidTransformation + 2D F-bar power **½**) is a FOLLOW-UP.
