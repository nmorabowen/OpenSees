| **Plane-strain out-of-plane stress σ_zz exposure** (apeGmsh request) — plane-strain elements report only `[σxx, σyy, σxy]` via `"stresses"`; the constitutive σ_zz (computed internally under ε_zz = 0) was discarded at the element boundary, making full-tensor invariants (von Mises, J2, triaxiality, Lode angle) inexact downstream — unrecoverable for nonlinear materials where σ_zz ≠ ν(σxx+σyy). Two additive pieces: (1) **material accessor** `virtual double NDMaterial::getStressZZ()` defaulting to **quiet NaN** ("not available" — never a misleading 0), overridden where the true value exists: `ElasticIsotropicPlaneStrain2D` (λ(ε₀+ε₁)), `J2PlaneStrain` (internal `stress(2,2)`), `PlaneStrainMaterial` wrapper (wrapped 3D 6-vector `σ(2)` — covers ANY 3D constitutive model), `DruckerPragerPlaneStrain` (`mSigma(2)`), fork `LadrunoJ2`/`LadrunoConcrete3D` (`stress6[2]` in DIM_PSTRAIN, NaN in other dims); (2) **element response** `"stressesPlaneStrain"`/`"stressPlaneStrain"` (responseID 21) = `[σxx, σyy, σxy, σzz]` per GP (ResponseType sigma33 on the 4th) on `FourNodeQuad`, `Tri31`, `LadrunoQuad` (SSP centroid mirrored ×4 like `"stresses"`), `LadrunoCST`, `BezierTri6`. Existing 3-component `"stresses"` untouched (backward compatible); NaN 4th component = "reconstruct elastically" downstream contract. Note MSVC prints NaN as `-nan(ind)` in text recorders — readers should treat any non-finite token as NaN. **`.ladruno` recorder: works with ZERO recorder edits** (`recorder ladruno f -E stressesPlaneStrain` — the `-E` verb is generic, each bucket self-describes via the element setResponse XML): verified end-to-end on all 5 elements, `NUM_COLUMNS = 4·nGP`, `COLUMN_MAP/COMP_NAMES = "sigma11,sigma22,sigma12,sigma33"` per GP, NaN σ_zz round-trips HDF5 intact. Recorder-wiring follow-up: LadrunoQuad/LadrunoCST now emit full GaussPoint/NdMaterialOutput/ResponseType XML for the NEW token (they carried none, so the recorder's size-inconsistency workaround labeled the bucket `C1..C16`; legacy `"stresses"` buckets left as-is for byte-parity) + BezierTri6's new-token names standardized to `sigma11`-style (its legacy `sigma_xx` style stays on `"stresses"`) so the token reads uniformly across ALL plane elements. | Material accessor + element response | — (no new tag) | `SRC/material/nD/{NDMaterial,ElasticIsotropicPlaneStrain2D,J2PlaneStrain,PlaneStrainMaterial,LadrunoJ2,LadrunoConcrete3D}.{h,cpp}`, `SRC/material/nD/UWmaterials/DruckerPragerPlaneStrain.{h,cpp}`, `SRC/element/fourNodeQuad/FourNodeQuad.cpp`, `SRC/element/triangle/Tri31.cpp`, `SRC/element/ladrunoPlane/{LadrunoQuad,LadrunoCST}.cpp`, `SRC/element/bezierTriangle/BezierTri6.cpp`, `tests/test_planestrain_sigma_zz.py`, `tests/test_planestrain_sigma_zz_recorder.py` | shipped | [#525](https://github.com/nmorabowen/OpenSees/pull/525) + recorder-wiring PR |
