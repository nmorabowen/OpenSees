| `SRC/analysis/fe_ele/transformation/TransformationFE.cpp`, `SRC/analysis/fe_ele/transformation/TransformationFE.h` | `// Ladruno (ADR-80 P3)`: **new `getSPTangentForce(Integrator*)`** — the Kratos-style `b -= K*du_D` term, the piece a Transformation-eliminated DOF can never contribute through `getResidual()`. Builds `du` in the element's ORIGINAL dof space (zero except sp'd dofs, where it holds *prescribed total − committed nodal value*), forms `f = K du` with the element tangent at the **committed** state, and returns `T^t f` in the assembled dof space so the caller can post it with the element's ordinary `getID()` — whose `-1` entries drop the eliminated rows for free. Returns `0` (assembles nothing) when the element has no sp'd node **or** when every sp on it is homogeneous (`du == 0`), so plain `fix` boundaries cost one virtual call and no tangent formation. **Finding worth keeping: the pre-existing `getTangForce(const Vector &, double)` stub CANNOT be the hook ADR-80 D6 assumed it was** — it indexes a GLOBAL vector by `myID`, and an eliminated dof has `myID == -1`, so the prescribed increment is not representable in its argument at all. The stub is left untouched. **Purely additive: no stock caller, zero behaviour change unless `LadrunoLoadControl -tangentPredictor` is used.** | [#786](https://github.com/nmorabowen/OpenSees/pull/786) |
