| `SRC/material/nD/UWmaterials/ManzariDafalias.{h,cpp}` | `// Ladruno (ADR-86b)` **the substep-COUNT cap FLAG SEAM for `ModifiedEuler` — the third seam in this file, same shape as `mHonorTolRInME` and `mUseCurrentVoidRatioInG`.** `ManzariDafalias::ModifiedEuler()` bounds its adaptive substep only from BELOW (`dT_min = 1e-6`, `:1380`) and, at `dT == dT_min`, **force-accepts** the substep and advances `T` (`:1649-1663`) — so the update always "succeeds" and can legally cost ~10⁶ return maps per Gauss point per state-determination pass. ADR-90 GATE U measured what that is from outside: single `analyze(1)` calls of **11–34 min** (worst 2056 s, 59 % of one leg's entire budget in ONE step) while the stepping controller used **0 of its 80** pinned subdivisions and ended 6400–25000× above its own step floor. The integrator never failed, so nothing upstream could react. Three protected members added (`int mMaxSubstepsInME` — **0 = UNCAPPED = vanilla**, `int mSubstepsTakenInME`, `bool mSubstepCapHitInME`), set in **all four** constructors, the latter two reset at the top of `integrate()` (so the cap bounds a whole material update, not each of the several `ModifiedEuler` calls `MaxEnergyInc`/`MaxStrainInc` make inside one), and read at **exactly one site**, the top of `ModifiedEuler`'s `while (T < 1.0)`. Past the cap it does **not** force-accept: it flags, emits one throttled `opserr` line (PROCESS budget of 10 — every Gauss point is its own material object) naming tag/`T`/`dT`, and returns, leaving the COMMITTED state untouched (`integrate()` writes only trial members). The ADR-84 `strict_convergence` precedent. **Vanilla is bit-identical:** the guard is `mMaxSubstepsInME > 0 && ...` with the member 0 in every `ManzariDafalias` constructor, so it is one integer increment and one `0 > 0` compare per substep and no branch is ever taken; only `LadrunoSANISAND`'s `applyLadrunoConstants()` writes a non-zero value, from the new `-maxSubsteps N` flag. **`OPS_ManzariDafaliasMaterial`'s own `TanType` default of `0` (ELASTIC, `:93`) is deliberately NOT changed** — every existing vanilla deck and golden file depends on it; only the fork parser's default moved (0 → 2).
