| `SRC/material/nD/ASDPlasticMaterial3D/ASDPlasticMaterial3D.h` | `// Ladruno (ADR-94 wp/94b)`: no shared mutable state between instances, and revert means revert. (a) **Per-instance state** (ADR-94 M1/H1, F1) -- `Stiffness`, `dsigma`, `depsilon_elpl`, `intersection_stress`, `intersection_strain` were `static` members of `ASDPlasticMaterial3D<E,Y,P,tag>`, i.e. ONE copy shared by every Gauss point, element and material tag of a specialization, so the whole model was assembled with the tangent of the last GP integrated. They are ordinary members now (zero-initialised in both constructors -- Eigen fixed-size storage is not), and their out-of-class definitions are gone. The seven per-integrator `static VoigtVector depsilon` function-locals are plain locals. `getInitialTangent()` no longer assigns `Stiffness` (F1: a getter with a global side effect) -- it computes into a local and copies that to the return buffer. `getTangent()` gained a `Stiffness.isZero()` fallback to the elastic tangent at the committed stress, because a per-instance buffer starts at exactly zero where the shared static used to carry whatever the last instance had left in it. The per-tag `INT_OPT_*`/`GLOBAL_*` maps stay static: keyed by material tag, shared by design. (b) **Revert** (ADR-94 M6/H4, the `wp/94e-revert` row of the verdict's fix list, folded in): `revertToLastCommit()` -- every statement was commented out -- now does Trial <- Commit for stress/strain/plastic strain, `iv_storage.revert_all()`, `Stiffness` <- elastic tangent at the committed stress, and clears the scratch buffers; `revertToStart()` -- was `cerr << "not implemented"; return -1;`, discarded by `Domain::revertToStart()` and `OPS_resetModel()` alike -- restores the freshly-constructed state (stresses/strains zero, IVs from a snapshot, `first_step = true`, `stress_set_externally = false`) and returns 0. New members `iv_storage_initial` / `initial_iv_captured` hold that snapshot, taken once on the instance's first `setTrialStrain` (`utuple_storage` has `commit_all`/`revert_all` only, no initial-value facility). (c) **`getCopy()` copies `first_step`** (ADR-94 H14/F6) plus the snapshot fields; the default constructor now initialises `first_step` at all. | wp/94b-statics (ADR-94 fix wave 2) |
