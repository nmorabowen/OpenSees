| `SRC/system_of_eqn/linearSOE/umfGEN/UmfpackGenLinSOE.{h,cpp}` | `// Ladruno ADR-75 P1g`: **`addA` scatter — linear scan → binary search**, the UmfPack half of the fix ADR-75 P1f ([#636](https://github.com/nmorabowen/OpenSees/pull/636)) made for PARDISO. The stock inner loop rescanned the whole CSC column for every one of `idSize²` element entries, i.e. `O(idSize² × collen)`. ADR-75b's L3-0 profile measured it at **1322.8 ms of a ~19.2 s Lane-B step** and named it as the remaining half of the finding. New `ops_umfpack_findRow()` binary search over `Ai[Ap[col] .. Ap[col+1])`. **Legal because each column is strictly ascending — and that is now ENFORCED, not assumed:** it holds by construction (every column is built through `ID::insert`, a binary-search insertion into a sorted array with dedup), and `setSize` now also CHECKS it and returns −1 with a loud message otherwise. The check is O(nnz) once per `setSize` against an assembly loop that runs for the whole analysis — free, and it converts a future silent breakage into a loud one. Verified by brute force before building: **2.9 M probes over random ascending columns — empty columns, absent rows, out-of-range — 0 mismatches vs the linear scan.** Also mirrors P1f's **free miss detector**: the `k >= 0` test already exists, so `else missing = 1` costs a never-taken branch and turns "an element entry has no CSC slot ⇒ its stiffness is silently discarded" from undetectable into a once-per-SOE warning. **MEASURED** (same interleaved harness as P1f, `MKL_NUM_THREADS=1` so the exactness check is meaningful — see the threaded-PARDISO determinism quirk; two independent runs): **1.044–1.057× at 11.5k DOF, 1.031–1.027× at 26.5k**, `ux` **bit-identical in all four size × run combinations**. ⚠ **The win is SMALLER than PARDISO's and SHRINKS with size** (P1f got 1.098× at 26.5k, growing). That is not a defect, it is the same insight in mirror image: `addA` pays in inverse proportion to how expensive the solve already is.
