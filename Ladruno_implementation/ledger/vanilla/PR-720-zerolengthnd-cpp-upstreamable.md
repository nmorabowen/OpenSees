| `SRC/element/zeroLength/ZeroLengthND.cpp` | `// Ladruno` (audit following #709): **`getTangentStiff()`/`getInitialStiff()` assembled only the lower triangle of `A^T*kb*A` and mirrored it** (`for (j < i+1)` then `stiff(j,i)=stiff(i,j)`), which silently symmetrizes an unsymmetric `theNDMaterial->getTangent()`/`getInitialTangent()` — exactly the BezierTri6/BezierTet10 defect #709 fixed, found here on a second element family. Non-associated plasticity on a `zeroLengthND` element therefore corrupted Newton with no diagnostic. Fixed both functions to assemble the FULL `(i,j)` range and dropped the mirror loop; the scalar `the1DMaterial` term (inherently symmetric, a scalar times an outer product) is unaffected numerically. **Audit line-number drift note:** the audit's suggested repro material, `DruckerPrager3D` (order 6), cannot actually drive this element — it hits an UNRELATED pre-existing latent defect in `ZeroLengthND::setTransformation` (the fixed 3x3 `transformation` member is indexed by material order, so `order > 3` reads out of bounds); the regression test uses `DruckerPragerPlaneStrain` (order 3, same `rho_bar != rho` non-associated flow) instead, which exercises the identical assembly loop this PR changed without tripping the unrelated OOB. | `SRC/material/nD/UWmaterials/DruckerPragerPlaneStrain.cpp` | `// Ladruno` (audit following #709): **`getInitialTangent()` was a verbatim copy of `getTangent()`**, returning the condensed elastoplastic `mCep` (current, possibly unsymmetric under non-associated flow) instead of the elastic `mCe` — so the "initial" tangent drifted with plastic loading and was call-order dependent, unlike `DruckerPrager3D::getInitialTangent()` which correctly returns `mCe`. | `SRC/material/nD/UWmaterials/ContactMaterial2D.{h,cpp}`, `SRC/material/nD/UWmaterials/ContactMaterial3D.{h,cpp}` | `// Ladruno` (audit following #709): **`getInitialTangent()` returned the SAME `tangent_matrix` buffer `getTangent()` overwrites in place**, so the "initial" tangent depended on call order (whatever sliding/sticking state the last `getTangent()` call left behind) and was the ZERO matrix — a singular initial stiffness — on a freshly constructed material before any `getTangent()` call.
