| `SRC/material/nD/ASDPlasticMaterial3D/ASDPlasticMaterial3D.h` | `// Ladruno (ADR-84 P2a)`: fixes the two UPSTREAM silent-accept defects in `Backward_Euler`, both behind a new opt-in integration option `strict_convergence` (int, default 0 ⇒ byte-identical to upstream). (a) **Exhaustion-accept** — the scalar-Newton loop fell out of `max_iter` with no convergence check and dropped through to `ComputeTangentStiffness(); return 0;`, committing `f > tol_yf` as success (the persistence mechanism behind the Cerro Lindo M3 finding, 20 GPs at `f/(2c·cosφ) = +0.0299`). Now tracked by a `be_converged` flag; when the flag is on and the loop exhausts with `|Phi| >= tol_yf`, an `opserr` line naming tag/`|Phi|`/tol is printed and the method returns -1. `Phi` is re-evaluated after the loop because the last Newton update is never checked inside it. (b) **f-decreasing elastic early-exit** — the second disjunct accepted a step as elastic whenever `f` merely decreased by more than `tol_yf`, even with `yf_val_end > 0`, perpetuating an inadmissible commit instead of correcting it; with the flag on it additionally requires `yf_val_end <= tol_yf` (elastic unloading, `f_end < 0`, still exits). Plumbing: `set_constitutive_integration_method` gains a defaulted 9th arg, `+1` per-tag static map `INT_OPT_strict_convergence` (+ its out-of-class definition). The ADR-84 P0 `special_return` hook is upstream of the Newton loop and unaffected in both modes. See [[LEDGER_quirks]] (two entries). | [#744](https://github.com/nmorabowen/OpenSees/pull/744) |
