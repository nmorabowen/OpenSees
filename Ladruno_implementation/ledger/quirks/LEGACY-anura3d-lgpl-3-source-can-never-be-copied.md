### Anura3D (LGPL-3) source can NEVER be copied, ported, or hand-translated into this fork -- and the licence file you need to read is `COPYRIGHT`, not `LICENSE`
- **Bites:** anyone harvesting from the open-source geomechanics field for the soil / u-p lanes. Anura3D is the obvious candidate -- it is the only open MPM code shipping production two-phase AND three-phase formulations (`MPMDYN2PhaseSP.FOR`, `MPMDYN3PhaseSP.FOR`, `TwoLayerFormulation.FOR`, `MPMDYNUnsatConsolidation.FOR`) -- and it is on GitHub, which reads as "available".
- **Why:** there is **no `LICENSE` file at this repo root** -- the grant is in `COPYRIGHT`, and it is not BSD. It is a UC Regents grant limited to "educational, research, and non-profit entities for noncommercial purposes only", with everyone else confined to "internal purposes only" and commercial distribution requiring a separate agreement with UC's Office of Technology Licensing. A copyleft licence forbids adding restrictions to the licensed material; that grant adds exactly such a restriction. A hand-translation of a `.FOR` file to C++ is a derivative work of it, so "I rewrote it in my own words" does not help. Clean-room practice exists precisely because reading the source is the contaminating act.
- **Workaround/status (2026-08-23, ADR-86 §2):** Anura3D is **read-only** -- cite it, reproduce its PUBLISHED equations from the papers, do not open its `.FOR` files while writing fork code. Contrast: **OpenGeoSys 6 is BSD-3-Clause** and **CB-Geo `mpm` is MIT** -- both may be reused with attribution; `cb-geo/mpm-benchmarks` is CC-BY-4.0 for inputs and data. **CODE_BRIGHT ships compiled binaries only** (a GiD problemtype), so it is a theory and benchmark reference and there is no source to take. This is an engineer's reading of licence text, not legal advice; a real check is owed before anything Anura3D-shaped becomes code.
