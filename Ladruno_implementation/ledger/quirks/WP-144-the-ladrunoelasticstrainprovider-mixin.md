### The `LadrunoElasticStrainProvider` mixin: NDMaterial must stay the FIRST base, the strain is the TRIAL one in engineering Voigt, and only the wrapper's DIRECT inner is asked (WP-144 G2)
- **Bites:** `LogStrainNDMaterial` finds the mixin with `dynamic_cast<LadrunoElasticStrainProvider*>(theMaterial)`. Three ways to get it silently wrong. (1) `LadrunoNorSand` is `public NDMaterial, public LadrunoElasticStrainProvider`: the OPS parsers return `new LadrunoNorSand3D(...)` through a `void*` that the caller reinterprets as `NDMaterial*`, which is only valid while NDMaterial is the first base (offset 0). Swapping the base order makes every `nDMaterial` command hand back a mid-object pointer. (2) The provided strain must be the TRIAL eps^e that belongs to the stress `getStress()` returned (after `setTrialStrain`, before commit) and in ENGINEERING Voigt (shear doubled; the kernel keeps tensor components): a committed or tensor-shear strain builds a b^e that is wrong by a shear factor of 2 or by one step, and only a shear-carrying plastic step shows it. (3) Only the wrapper's direct inner is tested: another wrapper between them does not forward the mixin, so the fallback inv(D0) route runs for the inner behind it. Which wrappers can sit there: `InitDefGrad` wraps `LogStrain` from OUTSIDE (`InitDefGrad -> LogStrain -> LadrunoNorSand`), so it never sits between them and the provider route is unaffected; only `StagedStrain` (small-strain, it takes the NorSand) can sit BETWEEN (`LogStrain -> StagedStrain -> LadrunoNorSand`), and then the D0 fallback applies. The `LogStrain` / `LogStrain2D` nDMaterial commands print a construction-time WARNING for exactly that deck (`ladrunoWarnStagedProviderInner`, fired once per command, not per Gauss point); stage with `InitDefGrad` outside the wrapper instead.
- **Rule:** keep NDMaterial first; return false (leave `epsE` untouched) when unavailable, never a stale value, because false selects the fallback; the fallback must stay byte-identical for inners without the mixin (check with a non-provider inner such as LadrunoJ2 under `LogStrain`, unchanged to round-off).
- **Workaround/status:** DONE (G2): `LadrunoNorSand::ladrunoGetElasticStrain` returns `sT.eps_e` with the shear components doubled for all dimensional views (always 6 components), false if `initOK()` is false or the state is non-finite. A refused trial leaves `sT = sC`, which matches the frozen stress the wrapper then reads. `LogStrain2D` composes `LogStrainNDMaterial` and so inherits the provider route with no code of its own.
