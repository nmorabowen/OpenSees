### `LogStrain` recovers eps^e = D0^-1 : tau, which assumes a LINEAR-ELASTIC inner: with a pressure-dependent shear modulus (LadrunoNorSand alpha0 != 0) `LogStrain(LadrunoNorSand)` is NOT OBJECTIVE (WP-144 G2; FIXED for inners that provide eps^e, the D0 path is the fallback)
- **Update (WP-144 G2, owner decision 2026-10-01, option c):** `LogStrainNDMaterial` now asks the inner first. If `dynamic_cast<LadrunoElasticStrainProvider*>(inner)` is non-null and `ladrunoGetElasticStrain` returns true, b^e is built from the PROVIDED trial eps^e (provider route, `LadrunoNorSand`); otherwise the old inv(D0):tau code runs unchanged (fallback route, every other inner, byte-identical). The text below describes the fallback route and why it is wrong for a pressure-dependent inner; see the entry on the mixin below for the provider route.
- **Bites:** `LogStrainNDMaterial::setTrialF` commits the elastic left Cauchy-Green by recovering the elastic strain through the inner's INITIAL tangent, eps^e_{n+1} = inv(D0) : tau (LogStrainNDMaterial.cpp, comment "v1 assumes a linear-elastic inner law"). The BA06 energy of LadrunoNorSand has K = -p/kappa_hat and mu = mu0 + alpha0 p~, so tau = D(eps^e) : eps^e is not D0 : eps^e.
  - alpha0 = 0 (constant mu): the deviatoric recovery eps^e_dev = s / 2 mu0 is exact, and the isotropic error in the volumetric part cancels exactly in b^e,tr = F_d b^e_n F_d^T (e^{2c} factors out of the log). `LogStrain(LadrunoNorSand)` is then objective to round-off: a rigid rotation of 0.2 rad after 10 plastic K2 steps (|R s R^T - s| = 24.3 kPa, so not vacuous) gives stress 9.5e-16, pi_i 0 and v 0 relative change.
  - alpha0 != 0: the deviatoric recovery is wrong and a rigid rotation (no deformation) changes the Cauchy stress relative to R sigma R^T and DRIFTS pi_i. Same rotation, measured (G2, `test_g2_logstrain.py::test_rigid_rotation_is_objective_with_pressure_dependent_shear_modulus`): alpha0 = 2 gives stress 2.35e-3 (relative to max|sigma|) and pi_i drift 9.8e-4 |p0|; alpha0 = 50 gives 3.6e-2 and 2.4e-2 |p0|. v is unaffected (2e-16).
  - The same cause also needs `getInitialTangent` to be the INITIAL elastic tangent (it is: tested in `tests/test_ladruno_norsand.py`); the base default `getTangent()` would make the recovery depend on the plastic state.
- **Rule:** the fallback route (inv(D0):tau) is valid only for a LINEAR-ELASTIC inner. Do not lift any other pressure-dependent-shear (nonlinear hyperelastic) material with the generic wrapper unless it implements `LadrunoElasticStrainProvider` (companion of "The generic LogStrainNDMaterial wrapper is UNSOUND for a stiffness-degrading inner"). `LadrunoNorSand` implements it, so alpha0 != 0 is supported under `LogStrain` through the provider route.
- **Workaround/status:** DECIDED and WIRED (G2 option c, 2026-10-01): provider route in `LogStrainNDMaterial.cpp` (`// Ladruno WP-144 G2`) + mixin in `LadrunoNorSand`. The alpha0 != 0 gates in `test_g2_logstrain.py` are REAL gates now (the `xfail(strict=True)` markers are gone; `test_rigid_rotation_is_objective_with_pressure_dependent_shear_modulus` and the wrapper-vs-O2f gates pass or fail on their own).
