### A floored LadrunoNorSand point's image pressure collapsed under the floored stress until every step size was refused (H19); fixed by the rule (S.57)
- **Bites:** Kimura strip deck at B/16 (HAR, K3 set, `-pmin` 0.505 kPa): four Gauss points beside the footing edges were committed ON the p' floor with `F = +2.8 ... +3.3 p_min` and then refused every increment, at every ladder level (`local_linesearch:pi_fold`, `local_noconv`), so the analysis stalled at s/B 0.143. Cause (sheet 144a §9.7, round 4): step 5f restores `p = -p_min` but kept `pi_i` from the PRE-floor converged state, whose hardening target `pi_i* = p_c B^((N-1)/N)` scales with `p_c`, and `p_c` lies on the surface of size `pi_i`: with `psi_i > 0` the map is a contraction towards 0 (`pi_i` -0.32 -> -0.11 kPa in 8 steps). It does NOT need large steps (2e-4 steps reach the same end, later). The round-3b argument "with `|p| >= p_min` the hardening target stays bounded away from 0" used the floored p; the algorithm uses `p_c`. A trial that starts several `p_min` outside F is not continuous with any solution, so smaller steps cannot help.
- **Rule:** after a post floor, if `F(sigma_f, pi_i) > 0` (strict) move `pi_i` onto the surface THROUGH the floored stress, `pi_i := min(pi_i, pi_f(sigma_f))` (sheet (S.57), owner decision O13 option A); never shrink the surface, never refuse (the `eta_f >= M/N` guard is proved unreachable). This makes `F <= F_tol` and `|pi_i| >= c_N p_min` hold at every committed state reached from an admissible start ((S.58)): the bound comes from the yield surface, not the hardening law. In a substepped increment the `S^pi` chain row of a sub-increment where the rule fired is REPLACED by (S.59), not corrected; keeping the (S.54) row (the H19 prototype `out/h19/h19_protoA.py`) is 0.20 off the FD of the increment, and a single-step tangent test cannot see it (gate: a forced (1/2, 1/2) ladder with the reset in the NON-final sub-increment).
- **Also:** the rule changes the continuum model on the floor (the split converges to (S.60), not the Koiter form (S.55)): where it fires persistently `pi_i` is slaved to the stress and the floored strength stops following `psi_i` (q +38 % on the K3 path). A legacy (round-3b) committed state with `F > 0` is NOT repaired at entry: the first converged post-floored step repairs it; a non-converging return is still refused. Inside the noise band `|F(sigma_f, pi_i^BE)| <= F_tol` whether the rule fired is not reproducible between implementations (state parity holds; counter and chain-row parity are asserted outside the band only).
- **Workaround/status:** FIXED in the kernel (`LadrunoNorSandKernel.h` return_map step 5g, chain_propagate (S.59)) and wired in the shell (`floor`[5] = `n_f_pi`, `stepInfo`[11..12] = `floor_pi`, `floor_pi_guard`, wire 113); gates in `tests/ladrunonorsand_kernel_check.cpp` (K1.12 (C), K1.14b, K1.16, (S.58) census, (S.59) FD) and the `MR*` mutants of `kernel_parity/mutate_kernel.sh`. O2 parity and the deck re-run: the orchestrator's final gate.
