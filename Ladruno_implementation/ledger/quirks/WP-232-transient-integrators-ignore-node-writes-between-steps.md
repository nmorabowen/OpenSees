### Transient integrators keep their own U, U̇, Ü and read the Nodes only in `domainChanged()` — node writes between steps are silently discarded

- **Bites:** anything that sets nodal displacement, velocity or acceleration between two steps of a running transient analysis and expects the next step to start from it: an MPM grid reset and particle-to-grid projection (WP-232), a mid-analysis state injection, a velocity "kick". Writes through `Node::setTrialDisp/Vel/Accel` + `commitState()`, or `ladrunoSetNodeTrial`, reach the Node objects, and the next `newStep()` ignores them. Nothing warns.
- **Why:** `Newmark::newStep()` predicts from its own cached vectors — `(*Ut) = *U; (*Utdot) = *Udot; (*Utdotdot) = *Udotdot;` (`Newmark.cpp:206-208`) — and pushes the prediction into the nodes; the only re-read from the nodes is `Newmark::domainChanged()` (`:398-414`, `DOF_Group::getCommittedDisp/Vel/Accel`). HHT (`HHT.cpp:329-345`) and Generalized-α (`GeneralizedAlpha.cpp:337-353`) follow the same pattern. And `DirectIntegrationAnalysis::analyzeStep` calls `domainChanged()` only when the domain stamp moved (`DirectIntegrationAnalysis.cpp:207-217`). `CentralDifferenceLadruno` re-seeds (`seedFromCommitted`) only in `domainChanged()` and `revertToLastStep()` (`:360`, `:518`), and each re-seed sets `firstStep = true` (`:362`, `:523`), i.e. a starter step. Static integrators (LoadControl, DisplacementControl) hold no nodal vectors and are unaffected.
- **Workaround / status (2026-11-13, WP-232 — disclosed, not changed):** injected nodal state is honoured only on a step whose `domainChanged()` runs — a fresh model's first `analyze`, or a step after `Domain::domainChange()`, which the injecting code must raise itself. For Newmark, HHT and Generalized-α (and the `LadrunoHHT` / `LadrunoGeneralizedAlpha` subclasses, which inherit it), raising `domainChange()` is a correct re-seed. For CentralDifferenceLadruno, the SMS integrators, LadrunoDynamicRelaxation and the multi-step methods (TRBDF2, Houbolt, …) a re-seed restarts the method's own state and is not a correct way to inject state.
- **Related:** `WP-215-domainchanged-not-idempotent.md` is the other face of the same cache — calling `domainChanged()` "to be safe" mid-transient cuts a CentralDifference history. `LEGACY-an-integrator-without-its-own-reverttolaststep.md` covers what a retry does to an integrator's cached state.
