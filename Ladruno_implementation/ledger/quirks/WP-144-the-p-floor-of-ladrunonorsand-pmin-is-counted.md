### The p' floor of LadrunoNorSand (`-pmin`) is COUNTED, never refused, and a floored point has ZERO bulk stiffness: the tangent is the exact one-sided linearisation, not a regularised one (WP-144 round 3)
- **Bites:** three readings of "floor" are tempting and all wrong here. (1) A floor that refuses (the old `p >= 0` / HAR out-of-domain refusals) kills every deck whose free-surface ring dips under `p_min`; the floor is a PROJECTION of the elastic strain at fixed deviatoric part (sheet 9.7 (S.48)), applied at the trial and after convergence, never inside the local Newton or the nested pi_i solve. (2) A floored point is NOT a yield-consistent point: `F(sigma_f) <= F_tol` is not asserted at a floored committed state (after a wet-side post floor F/p_min = +0.27 ... +0.82; the next trial sees `F_tr > F_tol` and returns). A test or a deck check that asserts it fails for the right reason. (3) At a floored state `delta : C = 0`: the pressure is pinned, so the consistent tangent has NO volumetric stiffness, only the energy's deviatoric stiffness at `|p| = p_min`. A global solver on a fully floored patch can stall on the volumetric DOFs.
  - The floor injects energy: `E_f` (S.52) is in `[0, W_f]`, `W_f = p_min * eps_f_v`. `W_f` is ALWAYS counted (State, response `floor`); `E_f` is a diagnostic of the increment from the closed-form Psi (response `floorEnergy`), never fed back into the state, the tangent or a refusal decision.
  - Under HAR the dry-side return does NOT always clear the floor: pattern `FPf` (trial floored, plastic, post floored) is an ordinary outcome (sheet 9.7 item 2, K1.14b). Do not write a gate that assumes `FP-` is the only dry-side pattern, or that a post floor is a wet-side event.
- **Rule:** the material keeps the EXACT tangent (owner decision 2026-10-03); any stiffness added for a floored patch is a SOLVER-side, tangent-only, opt-in, declared regularisation, never a kernel change (it would change the convergence path but not the converged answer, and keep the FD/parity gates valid). `-pmin 0` switches the floor off and restores the pre-round-3 refusals. The default is `5e-3 p_ref` (`p_ref = |p0|` under BA06, `p_a` under HAR), so a default deck at 100 kPa floors at 0.5 kPa: a test that used to see a refusal near `p -> 0` now sees a floored, counted state.
- **Also:** the LogStrain provider returns the POST-FLOORED trial `eps^e` (it reproduces `sigma` exactly and lies in dom Psi), so the wrapper rebuilds `b^e_n` from it and `Delta eps^f` joins the inelastic part of the split. The wire is APPEND-ONLY (`WIRE_LEN` 112: the round-3 fields sit at offsets 86 ..), so every older offset is unchanged.
- **Workaround/status:** IMPLEMENTED (WP-144 round 3, kernel `floor_project` / shell `LadrunoNorSand.cpp`); shell responses `floor` (alias `floored`) = `[at_floor, n_f_tr, n_f_post, eps_f_v, W_f]`, `floorEnergy` = `[E_f last increment, E_f cumulative incl. the trial increment, W_f]`, `floorInit`, and `stepInfo[9..10]` = `floor_tr, floor_post`; the initial-state event is counted in `W_f` but has no `E_f`. Gates (test author): K1.12 - K1.15, the (S.32f) / (S.54) FD checks, M-F1 ... M-F9. Final gate pending.
#### Follow-up (WP-144 round 4, 2026-11-11)
- Reading (2) above is WITHDRAWN for the committed state: since sheet round 4 (S.57) a post floor that leaves `F(sigma_f, pi_i) > 0` moves `pi_i` onto the surface through the floored stress, so `F <= F_tol` and `|pi_i| >= c_N p_min` hold at every committed state reached from an admissible start ((S.58)); the trial-side statement (a floored trial need not be on F) stands. Why: the H19 collapse (quirk "A floored LadrunoNorSand point's image pressure collapsed ..."). `floor` gains `n_f_pi` at [5], `stepInfo` gains `floor_pi`, `floor_pi_guard` at [11..12], and the wire is 113 (the committed `n_f_pi` appended at offset 112).
