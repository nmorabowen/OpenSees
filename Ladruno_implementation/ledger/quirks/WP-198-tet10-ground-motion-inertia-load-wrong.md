### `TenNodeTetrahedron` under `UniformExcitation` gives the wrong base reaction with no warning (inertia load sized for 4 nodes)
- **Bites:** every `TenNodeTetrahedron` model driven by a ground motion (`pattern UniformExcitation`, or any load path through `addInertiaLoadToUnbalance`), on builds before WP-198 and on vanilla OpenSees until jaabell's fix lands there. A 48-element unit cube, all nodes fixed, `rho = 2`, constant `ag = 3`, gives a total base reaction of **0.339 on the fork, static and transient (`reactions -dynamic`)**, instead of `rho*V*ag = 6`. On jaabell's pre-fix build it was 7.042 static / 4.392 transient; the wrong value depends on which other Tet10 fixes the build has, so the number is not a fingerprint. Nothing fails, nothing warns; stdBrick on the same cube gives 6.
- **Why:** `addInertiaLoadToUnbalance` was copied from the 4-node tet: `static const int numberNodes = 4; numberGauss = 1;` -- it filled 12 entries of the acceleration vector and created the load vector with 12 entries, so `-M*RV` over the 30x30 mass was never formed, and `getResistingForce()` then subtracted a 12-entry load from a 30-entry residual. `getResistingForceIncInertia()` declared `static Vector res(12)`. `Vector` arithmetic is unchecked outside `_G3DEBUG`, so the mismatched sizes produced numbers instead of an error.
- **Fix (2026-10-15, WP-198):** jaabell `ac9e5f2dc` -- `NumNodes`, `NumGaussPoints`, `NumDOFsTotal`. Found by gaaraujo reviewing OpenSees/OpenSees#1833. Gate: `tests/test_wp198_tet10_sync.py::test_ground_motion_base_reaction_is_rho_v_ag`.
- **Lesson:** for any element copied from a sibling with a different node count, grep the inertia and load paths (`addInertiaLoadToUnbalance`, `getResistingForceIncInertia`, `addLoad`) for literal sizes (`= 4`, `(12)`), not just `getResponse`. The 4-to-10-node copy left three separate hard-coded sizes in this class (this one, the PR-692 `getResponse` buffer, `setParameter`'s `pointNum <= 1`). The rigid-body check that catches it: fix every node, apply a constant ground acceleration, and compare the summed reaction to `rho*V*ag`.
