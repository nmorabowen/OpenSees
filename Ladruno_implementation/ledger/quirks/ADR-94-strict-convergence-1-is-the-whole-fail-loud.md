### `strict_convergence 1` is the whole fail-loud contract for ASDPlasticMaterial3D — what it does and does not promise (ADR-94 wp/94a)
- **What it now covers (all integrators, not just `Backward_Euler`):** the eight `f`-decreasing "call it elastic" early exits additionally require `yf_val_end <= tol_yf`; BE's `dLambda + deltaLambda < 0` fallback refuses instead of committing the elastic predictor as success; ME/RK45 refuse an out-of-tolerance substep at `dT_min` instead of accepting it unconditionally; each integrator re-evaluates `yf` after its return-to-yield block and refuses on `f > tol_yf`; and BE's two pre-existing gates (special-return fallback, scalar-Newton exhaustion) are unchanged. Every refusal is `LADRUNO_MATERIAL_REFUSED` plus one `opserr` line naming the tag, the integrator and `|f|`.
- **What it still does NOT promise.** (1) The flag is OFF by default and off is byte-identical to upstream — a model that has never set it has none of this. (2) The check is `f > f_absolute_tol` with an ABSOLUTE tolerance in stress units, so the unit system still decides whether a state is refused (see the `f_absolute_tol` entry above). (3) `stdBrick` swallows the refusal anyway (`Brick::update()` returns 0 unconditionally); use `LadrunoBrick` or `TenNodeTetrahedron` for anything you want to fail loud. (4) It is an ADMISSIBILITY gate, not an accuracy gate: a state can pass `f <= tol` and still be the wrong point on the surface (ADR-94 M3/B5).
- **Rule:** turn it on for any softening or near-limit deck, and read a refusal as "cut the step", not as "the model is broken". A step that now fails where it used to converge is almost always a state that used to be committed wrong.
- **What flag-OFF actually costs (MEASURED, R4 matrix regenerated on `229842f7f`):** the strict helper is constant-false with the flag off, and the `Forward_Euler`, `Forward_Euler_Subincrement` and `Backward_Euler` rows of the R4 matrix regenerate **completely unchanged** across all 5 tangents and 3 paths. Every difference is confined to three integrators and is item-1/item-5 behaviour, not strict mode: `Backward_Euler_LineSearch` is now `crashed` (the parser refuses it, ADR-94 M7); and `Modified_Euler_Error_Control` / `Runge_Kutta_45_Error_Control` flip `ok` -> `refused` with **identical `|f|max`** because their bare `-1` used to be dropped by `LadrunoBrick`'s sentinel-only compare and is now heard. The ONE genuine numeric change in the whole table is `HoekBrown` x RK45 x compression, `5.55e-09` -> `2.35e-08` at the same iteration count -- HoekBrown uses `NullHardeningTensorFunction`, whose policy used to RETURN uninitialised Eigen storage (ADR-94 B4), so this is the Eigen-init fix showing up as a 1e-8 shift.
- **`compute_local_stress`'s gate is inert by construction:** its three callers are the numerical-tangent probes and all ignore the return code, so the site returns the sentinel for contract uniformity only. Do not use it as evidence that the numerical tangents are gated.
