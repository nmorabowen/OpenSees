# mpm_implicit_cases.txt -- cases for mode A, implicit and quasi-static MPM (WP-232f, ADR-232 §9
# phase 1). Format version: mpm-implicit-cases 1.
#
# Written by the verification worker (232f-V). Every expected number comes from a reference that
# is not the mode-A code: a closed form, an independent numpy solve, or a fork FE run (a different
# code path). The tolerances are the pre-registered gates of
# .claude/skills/ladruno-mpm/references/wp-briefs.md, section "232f" -- copied, never widened.
# The C++ worker (232f-C) reads THIS file; it never reads tests/mpm_implicit_reference.py.
#
# FORMAT -- that of tests/mpm_cases.txt (its header is authoritative for every key it defines:
# ndm, basis, origin, h, cells, material ... elastic, body ... box, shift, velocity, stress, fix,
# gravity, series, masscut, dt, steps, tol, expect, compare, note; the lattice seeding rule and the
# node / face numbering of tests/mpm_interface.md §2, §5). Units: any consistent set, stated per
# case. Sign: tension positive. Plane strain, thickness 1, when ndm = 2.
#
# Keys added or changed here:
#   kind      run | refusal | protocol
#             'protocol' cases state a behaviour test between two runs (retry, re-seed, restart,
#             recorder synchrony); their inputs are another case plus the listed switches.
#   mode      transient | quasistatic                 (mode A; required)
#   integrator newmark <gamma> <beta>                 (transient; this file uses 0.5 0.25 only)
#   newton    <test> <tol> <maxIter>                  suggested convergence test, OpenSees names
#             (NormDispIncr | NormUnbalance); the driver may tighten it, never loosen it
#   material  <tag> elastic <E> <nu> [rho]            nDMaterial ElasticIsotropic
#   material  <tag> druckerprager <K> <G> <sigma_y> <rho_dp> <rho_bar> <Kinf> <Ko> <delta1>
#             <delta2> <H> <theta> <massDen>          nDMaterial DruckerPrager (UW), arguments in
#             the order of its OpenSees command
#   series    none | linear <T_r>                     load factor lambda(t) = min(t/T_r, 1); it
#             scales gravity AND every pforce. dt is a pseudo-time increment when quasistatic.
#   schedule  <dt> <nSteps>                           repeatable; replaces dt/steps: the run takes
#             nSteps steps of dt, then the next schedule line (used by the retry reference)
#   pforce    <body> box <lo: ndm> <hi: ndm> <f: ndm> a constant external force on every particle
#             of the body whose INITIAL centre lies in the closed box, per particle (per unit
#             thickness in 2D), scaled by lambda(t). P2G'd as a particle external force.
#   gridvel   <name> box <lo: ndm> <hi: ndm> v <ndm tokens: value | free> [start <t0>] [track <axis>]
#             a prescribed-velocity grid condition (ADR §5.3: never a DisplacementControl
#             integrator on a grid node). Its node set at step n is every grid node (real or
#             ghost) inside the box, closed, with tolerance 1e-9 h. Before t0 the condition is
#             absent (its nodes are free). 'track <axis>': the box's lower bound on that axis
#             moves with the prescribed motion, lo(t_n) = lo + v_axis * max(t_n - t0, 0) evaluated
#             at the START of step n (a rigid body pushed into the material: rows the body
#             reaches join the set). In quasi-static mode the prescribed increment per step is
#             v * dt. Where a gridvel and a 'fix' act on one node component, both prescribe the
#             same value (0) or the case is malformed.
#   particles <filename> contract1                    the case's bodies are NOT seeded by the engine:
#             the harness seeds them by the rules here, writes them as one Contract-1 particle set
#             (ADR §7.2; the writer pattern of tests/mpm_contract_fixtures.py write_contract1,
#             validated by tests/mpm_contracts.py validate_particle_set) to <tmpdir>/<filename>,
#             and loads it with 'mpm particles -file {<path>}'. The 'seed_*' expects check that the
#             harness's seeding matches the reference's, before any step.
#   body      <id> holeplate <a> <half_width> <n_theta> <n_r> mat <tag> rho <rho>
#             the body-fitted O-grid seeding of the plate-with-a-hole case; the rule is stated in
#             full in that case's comment block.
#   status    gate | report | xfail                   gate (default): every expect is a pass/fail
#             gate. report: computed and printed, never failed. xfail: strict expected failure.
#             A single expect line may end in the token 'report' (that line only is report).
#   ref       <free text>                             where the expected number comes from
#   gap       <free text>                             the model-form gap between reference and MPM
#
# Observables added here (all at committed states; 'track' particles are chosen by INITIAL position):
#   tip_disp_y <x_from>          mass-weighted mean of (y_p - Y_p) over the particles whose initial
#                                x is >= x_from (the tip particle column), after the last step
#   tip_disp_y_history <x_from>  the same, recorded after every committed step (with t_k)
#   first_peak_tip_disp_y <x_from>  transient: the most negative value of the history before its
#                                first upward turn (the first local minimum; refined by the parabola
#                                through the minimum sample and its two neighbours)
#   first_period_tip <x_from>    transient: time between the first and second local minima of the
#                                history (each refined as above)
#   cond_force <name> <comp>     sum over the gridvel node set of the GRID INTERNAL FORCE
#                                f_int,i = sum_p V_p sigma_p . grad S_i(x_p) (OpenSees resisting-
#                                force sign), component comp, at each committed step. In a quasi-
#                                static step this equals the OpenSees nodal reaction plus the
#                                external (pforce) load lumped on those nodes -- the r_corr of the
#                                FE deck (Ladruno_files/testbed/hypo_bearing/dp_strip.py).
#   cond_pressure_max <name> <comp> <width>  max over committed steps of -cond_force / width
#   cond_pressure_plateau <name> <comp> <width> <t_from>  mean of -cond_force / width over the
#                                committed steps with t >= t_from
#   peak_sthth_over_snet <xc> <yc> <lig>  max over particles of sigma_thth,p / sigma_net, with
#                                theta = atan2(y_p - yc, x_p - xc),
#                                sigma_thth = sxx sin^2 + syy cos^2 - 2 sxy sin cos, and
#                                sigma_net = cond_force(load, y) / lig (the gridvel set named
#                                'load'; no pforce acts, so this is its reaction), after the last step
#   seed_count / seed_volume_sum / seed_moment   the seeded set before any step: N, sum V_p, and
#                                (sum V_p x_p, sum V_p y_p)
#   selfweight_error, period_comx, particle_fields   as tests/mpm_interface.md §10
#   g2p_count                    number of G2P passes the driver ran (an 'info' counter)
#   accepted_steps               number of accepted (committed) steps
#   relerr_ge <case> <field> <r> particle_fields of this run differ from <case>'s by at least r,
#                                max_p |a - b| / max_p |b| over the named field (v or x)
#   recorder_sync                every output record's positions and stresses equal the engine's
#                                in-memory particle state of the SAME accepted step (exactly)
#   refused                      the command or analysis is refused loudly and changes nothing
#   compare <obs> [args] relerrle <case>  the relative error of this case's <obs> against its
#                                own 'expect <obs> [args] eq' value is <= that of <case> against
#                                <case>'s own (the 'error non-increasing' relation)
#
# Resolution series: '_r1', '_r2', '_r3' are coarse, medium, fine. Per the gate table the gate

# The ADR-79 control (Ladruno_implementation/79_ladruno_geom_hypo_adr.md, "Validation, and two
# things it exposed"; deck Ladruno_files/testbed/hypo_bearing/dp_strip.py, leg nq20_nonassoc):
# weightless soil, surcharge q0 = 10 kPa, rigid strip footing B = 2 m, DruckerPrager (UW, built
# after 31322a47a) on the phi_txc = 20 deg cone, alpha = 2 sin20 / (sqrt3 (3 - sin20)) = 0.148583,
# rho_dp = sqrt2 alpha = 0.210128, NON-associated (rho_bar = 0), sigma_y = 0.2 kPa (the deck's
# apex regularizer), K = 1.5e5 kPa, nu = 0.45 (G = 3K(1-2nu)/(2(1+nu)) = 15517.24 kPa).
# Chen-Han plane-strain match: tan phi_ps = 3 alpha / sqrt(1 - 12 alpha^2) -> phi_ps = 27.47 deg,
# N_q = exp(pi tan phi) tan^2(45 + phi/2) = 13.89, q_u = q0 N_q = 138.9 kPa EXACT (Prandtl-
# Reissner; the bounds coincide; independent of footing roughness for weightless soil).
# Units kN, m, s (kPa). Half model (symmetry at x = 0): soil x in [0, 12], y in [-6, 0]; two empty
# cell rows above the surface for heave. Sides x = 0 and x = 12: rollers (fix x); base: fix xy.
# Stage 1, t in [0, 10]: the surcharge ramps on the top particle row (lambda = t/10), footing free.
#   Each top-row particle carries q0 * (h/2) downward (ppc 2: one particle per h/2 of surface).
# Stage 2, t > 10: the rough rigid footing = a gridvel on the nodes with x in [-h, B/2], both
#   components, v = (0, -0.002) m per unit pseudo-time, dt = 1: 2 mm per step, 100 steps to
#   s = 0.2 m (s/B = 0.10; the FE control plateaus from s/B ~ 0.05). 'track y' lowers the set's
#   bottom with the footing, so rows the footing reaches join it.
# Footing pressure q = -cond_force(footing, y) / (B/2), B/2 = 1 m per unit thickness.
# Gate (pre-registered): q_max at the finest within [0.90, 1.10] x 138.907 kPa = [125.02, 152.80].
# Particles (ppc 2): r1 (4 cells across B) 1152, r2 (8) 4608, r3 (16) 18432.

# P1 row: plate with a hole, d/W = 0.5
# ============================================================================
# Strip of width W = 4 m with a central circular hole of diameter d = 2 m (a = 1 m): d/W = 0.5.
# Howland's factor (Howland 1930, Phil. Trans. R. Soc. A 229:49-86, as tabulated in Pilkey &
# Pilkey, Peterson's Stress Concentration Factors, 3rd ed. 2008, Chart 4.1): K_tg = 4.32 at
# d/W = 0.5, so K_tn = sigma_max / sigma_net = K_tg (1 - d/W) = 2.16. Plane strain is the same
# stress field (traction-free hole, zero resultant on it: Michell). Quarter model (symmetry
# x = 0 and y = 0), x in [0, 2], y in [0, 4] (plate length 2W). The top edge y = 4 is pulled by a
# gridvel 'load' (v_y prescribed, v_x free): uniform end displacement, 1e-4 strain in one step.
# sigma_net = reaction(load, y) / (W/2 - a), ligament 1 m per unit thickness.
# Grid h = a/32 = 0.03125 (64 x 128 cells + 1 row above).
# SEEDING (both bodies written as ONE Contract-1 file, then read with 'mpm particles -file'):
#   O-grid region [0, 2]^2 minus r < a: n_theta = 256 cells in theta over [0, pi/2],
#   theta_i = (i + 1/2) (pi/2) / n_theta; n_r = 120 cells in s over [0, 1], s_j = (j + 1/2)/n_r;
#   rho_o(theta) = (W/2) / max(cos theta, sin theta) (the ray to the square's edge);
#   r(theta, s) = a + s (rho_o(theta) - a); particle i + n_theta j at r(theta_i, s_j) (cos, sin).
#   Volume = the exact area of the cell [theta_i +- dtheta/2] x [s_j +- ds/2], i.e.
#   integral over theta of (r(theta, s+)^2 - r(theta, s-)^2)/2, by 8-point Gauss-Legendre in theta
#   per cell (rho_o is smooth inside each cell: n_theta is even, no cell straddles pi/4).
#   GIMP half-lengths lp_x = min(sqrt(V)/2, x, W/2 - x), lp_y = min(sqrt(V)/2, y, W/2 - y): no
#   domain leaves [0, W/2]^2 (Contract 1, C1-POS). Ids 0 .. n_theta n_r - 1 in that order.
#   (Amended 2026-11-14 on 232f-C's report: the first rule, lp = sqrt(V)/2 on both axes, put
