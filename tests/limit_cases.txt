# limit_cases.txt -- analytic and formulation cases for limit analysis (WP-237a).
# Interface: tests/limit_interface.md. Format version: limit-cases 0.
#
# FORMAT (line based, ASCII)
#   '#' starts a comment line; blank lines are ignored. Tokens are separated by whitespace.
#   'case <name>' opens a block, 'end' closes it. Inside, each line is '<key> <tokens...>'.
#
#   status      active | todo
#   class       exact_on_mesh | exact_lower_on_mesh | one_sided_reference | upper_feasibility_3d
#   desc        free text
#   source      free text; repeatable
#   checked     <date> free text saying how the value was checked; repeatable
#   units       free text
#   box         x0 y0 z0 x1 y1 z1
#   mesh        nx ny nz                 structured Kuhn mesh (interface section 3.5); repeatable
#   mesh_file   <file>                   tet4 mesh under tests/data/limit/; repeatable
#   nested      i j                      mesh j is the uniform refinement of mesh i
#   formulation <id>                     formulation the assertions were written for; repeatable
#   phi_deg     <deg>                    friction angle behind a plane-strain matched alpha, k
#   region      <name> von_mises k <k> [b0 x y z] [b1 x y z]
#   region      <name> drucker_prager k <k> alpha <a> [b0 x y z] [b1 x y z]
#   footing     <name> xref x y z law bonded
#   boundary    <name> <kind> plane <x|y|z> <c> [range <x|y|z> lo hi]... [t0 x y z] [t1 x y z]
#               [t0_affine c0 c1 c2 g00 g01 g02 g10 g11 g12 g20 g21 g22] [t1_affine ...]
#               [footing <name>]
#               A facet belongs to the FIRST line whose plane and ranges hold at all three of
#               its vertices. Every exterior facet must match. t(x) = c + G x.
#   query       <id> ray
#   F0, F1      <footing> Fx Fy Fz Mx My Mz      default zero
#   restrained  <footing> <ux|uy|uz|rx|ry|rz>...
#   target      <value> formula <name> [key=value ...]   |   target none
#   assert      lower_le_target <tol> | upper_ge_target <tol> | lower_ge_target <tol>
#               | gap_le <value> | upper_le_formula <name> [key=value ...]
#               | feasibility_status formulation_feasible
#   on_failure  formulation_result           required by class upper_feasibility_3d
#
# One-sided meaning, with T the target and L, U CERTIFIED values:
#   lower_le_target tol   L <= T + tol*|T|
#   upper_ge_target tol   U >= T - tol*|T|
#   lower_ge_target tol   L >= T - tol*|T|   only where the exact field lies in the Lower space
#   gap_le g              (U - L) / ((U + L) / 2) <= g
# An estimate never satisfies an assertion.
#
# Every target is valid for the stated box, with its exact wall conditions. See interface
# section 16 for each derivation. 'checked' says what was actually done; no primary text was
# read unless a line says so.
