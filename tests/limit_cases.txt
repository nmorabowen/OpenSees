#               | gap_le <value> | gravity_work_eq <tol>
#               | lower_ge_formula <name> [key=value ...] | upper_le_formula <name> [key=value ...]
#               | lower_le_formula <name> [key=value ...] | upper_ge_formula <name> [key=value ...]
#   gate        kinematic_status formulation_feasible
#               | certified_upper mesh <i> | certified_bracket mesh <i>
#               | gap_le <NAMED_LIMIT> mesh <i>
#               | upper_nonincrease <i> <j> | lower_nondecrease <i> <j>
#   record      gap mesh <i>             reported in the verdict; it gates nothing

# Executable meaning: evaluate_case in tests/test_limit_contract.py, described in interface 17.9.

#
# One-sided meaning, with T the target and L, U CERTIFIED values:
#   lower_le_target tol   L <= T + tol*|T|
#   upper_ge_target tol   U >= T - tol*|T|
#   lower_ge_target tol   L >= T - tol*|T|   only where the exact field lies in the Lower space
#   lower_ge_formula      L >= formula - TOL_CASE_ONE_SIDED*|formula|   an explicit Lower field exists
#   upper_le_formula      U <= formula + TOL_CASE_ONE_SIDED*|formula|   an explicit Upper field exists
#   lower_le_formula      L <= formula + TOL_CASE_ONE_SIDED*|formula|   the formula bounds the collapse load above
#   upper_ge_formula      U >= formula - TOL_CASE_ONE_SIDED*|formula|   the formula bounds the collapse load below
#   gap_le g              (U - L) / ((U + L) / 2) <= g; a bracket with status order_within_floor counts as gap 0
# Floors are not added: the one-sided tolerances are the allowance for them.
# An estimate never satisfies an assertion or a gate.
