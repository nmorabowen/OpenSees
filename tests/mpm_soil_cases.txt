# S1 -- one-point drivers (LadrunoBrick -geom hypo -formulation std, unit cube, every node
# prescribed u = (F - I) X, zero free equations). Both materials, 3D and plane strain (the FE
# plane-strain leg is the 3D brick with u_z = 0 and the 3D material; LadrunoSANISANDPlaneStrain
# zero-embeds into the same 6-vector integrator). Path: isotropic stage-0 confinement to p0 =
# 100 kPa in 10 steps (3D: F_ii = 1 - a, a = p0 / (3 K_stage0); plane strain: xx, yy only,
# a = p0 / (2 K_stage0)), the flip (updateMaterialStage: one element, so all 8 points, with
# Elastic2Plastic) before step 11, then:
#   triax  40 steps to F_yy = 1 - 5e-3 (x and z: 1 + 0.25 e; plane strain x only)
#   oedo   40 steps to F_yy = 1 - 5e-3, lateral fixed
#   shear  3 cycles of isochoric simple shear F_xy = gamma, amplitude 2e-3, 10 steps per quarter
#          (0 -> +ga -> -ga -> 0 per cycle; 120 steps), applied as S F_conf
# The record gives F[n], dF[n] = F[n+1] F[n]^-1 (L = (dF - I)/dt), and per step sigma, state,
# SANISAND substeps (GP 1, and at all 8 GPs).
# FE SELF-CONSISTENCY (a fact for the S1 tolerance, measured before any MPM number): the 8 Gauss
# points of one homogeneous brick see F to round-off (their dN/dX differ). For SANISAND scheme 1
# they part at the 3rd plastic step: 3D triax first step with GP rel spread > 1e-8 = 13 (3rd
# plastic step; GP substep counts still EQUAL there: 3,3,...,3, they first differ at step 14),
# 3D oedo 13 (14), 3D shear 14 (14), PS triax 24 (30), PS shear 15 (16), PS oedo never; max GP
# rel spread 1.1e-4. HS: never (max 2.5e-13). So "rel 1e-8 against the FE" is unreachable by the
# FE itself for SANISAND triax/oedo past those steps, and the freeze's substep-count switch can
# come one step late (3D triax: the spread opens at 13, the counts differ at 14). Per-leg values
# are fe_self_consistency in the record.
case s1_ref_onepoint
kind reference
data tests/data/mpm/soil/s1_onepoint.json
field legs.<sanisand|hs>_<3d|ps>_<triax|oedo|shear>.{F, dF, steps[k].{sig, state, substeps, substeps_gp, gp_rel_spread}, fe_self_consistency}
ref fork FE, LadrunoBrick -geom hypo (hypoIncrement; the particles use hypoIncrementFromF: same algebra, different rounding)
end
