# WP-232i — the B-spline basis and the manufactured-solution orders: each row's parameters and
# its gate, copied from the pre-registered table in .claude/skills/ladruno-mpm/references/
# wp-briefs.md ("232i", fixed before any B-spline number existed; G1-K4 and G8 added at the
# freeze, before any number). A band is never widened: a miss is reported as a miss.
#
# Format: `row <name>` ... `end`. Keys:
#   status   gate | report
#   gate     the gate, verbatim from the table (documentation; the test asserts the parsed form)
#   p_ge     order threshold p (least-squares slope of log e vs log h over the three finest rungs)
#   nonincr  1: e must be non-increasing along the whole ladder
#   mode     explicit | quasiStatic | implicit (mode A transient, Newmark average acceleration)
#   basis, ndm, ppc, fmax (max |F_ii - 1| = 2 pi A), flip (alpha_F), ladder (1/h rungs),
#   steps (quasi-static load steps), dt_rule (explicit: a multiple of the finest rung's critical
#   dt), validity (|e(dt/2) - e(dt)| / e(dt) < this at the finest rung, else dt is halved)
#
# Common to every MMS row (tests/mpm_mms.py): unit square / cube, rollers on every face
# (`mpm fix xmin x`, `xmax x`, `ymin y`, ... ; K4 images on B-spline grids), ElasticIsotropic
# E = 1, nu = 0.3, rho0 = 1, u_i = A sin(2 pi X_i) sin(c pi t) with c = 2 (period T = 1),
# t_end = T. The body force is set every step with `mpm particleBodyForce`, at t_n (mode F) or
# at t_{n+1} / lambda_{n+1} (mode A); the initial velocity with `mpm particleVelocity`.
# e = sqrt(mean_p |u_p - u(X_p, t_end)|^2) / A. Reported with every leg: e(T/4), max_t e(t),
# cell crossings per rung (particle-steps whose cell index changed), dt, wall time.

status gate

basis bspline2 bspline3
ndm 2 3
tol_pu 1e-13

tol_lin 1e-12
tol_lingrad 1e-11

end
