# mpm_cases.txt -- engine cases for the explicit MPM driver (WP-232b).
# Interface: tests/mpm_interface.md. Format version: mpm-cases 1.
#
# FORMAT (line based, ASCII)
#   '#' starts a comment line; blank lines are ignored. Tokens are separated by whitespace.
#   'case <name>' opens a block, 'end' closes it. Inside, each line is '<key> <tokens...>'.
#   Keys may repeat; repeated keys keep their file order. Numbers are C/Python floats.
#   The bare token 'pending-oracle' marks a value the phase-2 numpy oracle fills in.
#
#   kind      shape1d | shape | critdt | masscut | run
#   desc      free text to end of line
#   ndm       2 | 3                     (2 = plane strain, thickness 1)
#   basis     gimp | linear             (default gimp; interface section 4)
#   origin    <ndm floats>              grid minimum corner (section 2)
#   h         <float>                   cell size, all axes
#   cells     <ndm ints>                cell counts
#   material  <tag> elastic <E> <nu>    hypoelastic isotropic (section 9)
#   body      <id> box <lo: ndm floats> <hi: ndm floats> ppc <n> mat <tag> rho <rho>
#   body      <id> disc <cx> <cy> <R> ppc <n> mat <tag> rho <rho>              (2D)
#             lattice seeding, ordering and ids: interface section 5
#   velocity  <body> uniform <ndm floats>
#   velocity  <body> sine <comp> <axis> <v0> <beta> <x_ref>
#             v_comp = v0 * sin(beta * (X_axis - x_ref)), other components 0; comp/axis in x|y|z
#   stress    <body> geostatic <y_top> <rho> <g> <K0>
#             2D only: sig_yy = -rho*g*(y_top - y), sig_xx = K0*sig_yy, sig_xy = 0 (Voigt [xx yy xy])
#   particle  <id> <body> <mat> <rho> <V0> x <ndm> lp <ndm> v <ndm> s <nv>
#             an explicit particle; m = rho*V0; s = initial stress, Voigt, tensor shear
#   point     <ndm floats> lp <ndm floats>         (kind shape: the one particle evaluated)
#   fix       <face> <components>       face in xmin..zmax; components a string over x,y,z
#   wall      <face> <mu>               stationary Coulomb wall (section 7)
#   gravity   <ndm floats>              body force per unit mass, signed
#   series    none | linear <T_r>       load factor (section 6.2); default none
#   damping   <alpha_D>                 default 0
#   flip      <alpha_F>                 default 1
#   masscut   <c_m>                     default 1e-10
#   safety    <s>                       default 0.5
#   dt        <float>
#   steps     <int>
#   tol       <abs> <rel>               default tolerance of the case's 'eq' expectations
#   expect    <observable> [args...] <op> <values...|pending-oracle> [tol <abs> <rel>]
#             op: eq (|got-exp| <= abs + rel*|exp| elementwise), le (got <= value), ge (got >= value)
#             observables: interface section 10. Special forms:
#               expect s1 <h> <lp> <r> eq <S> <dS/dr>                      (kind shape1d)
#               expect node <id> eq <S> <dS/dx> <dS/dy> [<dS/dz>]          (kind shape)
#               expect refused            /   expect accepted
#             A 'kind shape' case lists every support node with non-zero S or gradient;
#             any other node must have S = 0 and zero gradient.
#   compare   <observable> [args...] <lt|gt> <other case name>   a relation between two cases
#   note      free text
#
#   Observables of 'run' cases are evaluated at step 0 and after every committed step; '*_end'
#   and 'particle_fields' use the state after the last step.
#   particle_fields: the expect line reads 'expect particle_fields eq fields tol <abs> <rel>' and is
#   followed, inside the case, by one line per particle (Amendment 3):
#     field <id> x <ndm> v <ndm> F <ndm*ndm> V <1> sig <nv> sighat <nv> epshat <nv>
